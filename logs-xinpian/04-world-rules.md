# 《服管足行志（Logs）》· 第 2 步 世界观与规则确认

## 世界

- **凌霄**：一个中小型 Minecraft 生存服务器（小镇格局），人口几十人。街道、民居、商铺、广场、市政厅、钟楼、红石工坊、路灯、公告栏、树洞信箱、镇口牌坊。
- **时代/现实基准**：方块世界规则为底层（方块、红石、铁锭货币、村民交易、末影珍珠、狼、动物）。服务器为和平生存（无怪物威胁），秩序靠"服管会"与镇规维持。
- **基调**：生活类日常悬疑，无血、无死亡、无重伤；最严重的后果是"被除名 / 被赶出小镇 / 失联"。

## 社会规则

- **镇规**：不偷、不破坏他人建筑、公共区域共同维护、遇到异常可举报。
- **举报机制**：举报信投树洞信箱/公告栏。举报需可追溯（署名或至少能查到来源）；一集内出现大量"来路不明的匿名举报"本身就是疑点。
- **服管会**：由服管与若干协助者组成，负责查记录、实地调查、提出处理建议。
- **镇公所**：重大决策机构，有最终裁决权（如除名），也有权给服管下限期。

## 特殊规则与能力边界

- **co 记录（CoreProtect）**：记录方块操作（放置/破坏/交互）的操作者与时间，服管可查询。
  - **边界 1**：co 记录"谁操作"，不记录"谁指使"（帮忙/代管/雇人的幕后查不到）。
  - **边界 2**：co 记录账号，不记录真人。他人离线时段登录的账号、代管账号，记录指向账号而非真身（即"借名"成立的基础）。
  - **边界 3**：co 不记录聊天、不记录动机。记录可靠，但不是"人的全部"。
  - 全季只在 B3（不记"指使"）点出一次能力边界；**co 不无故失效**，老穆靠借名+修证据链躲避，不靠魔法失效。
- **红石机关**：可造自动装置（活塞、压力板、发射器、命令方块之外的纯红石），是"异常"与"打戏"的物理基础。无血打斗=击退、摔落、跑酷、缴械、活塞/水/网困住。
- **铁锭**：通用货币；交易、雇佣帮手都走铁锭。
- **镇史库**：钟楼地下的初代封存处。按镇规，封口需镇公所程序才能开启。老穆绕过程序抢先撬，是冲突点而非规则漏洞被滥用。

## 组织权限

| 主体 | 权限 |
|---|---|
| 服管 | 查 co、实地调查、提出处理建议；不能凭空认定操作者身份（必须 co 或人证） |
| 镇公所 | 给限期、停权、最终裁决（除名）、决定镇史库处理 |
| 老穆（个人） | 无官方权限，靠"维修"信任与代管旧号操作 |
| 普通玩家 | 受保护、可举报、可被调查 |

## 硬规则（不可临时突破）

1. 服管不能无凭据指认任何人；每条指控必须有 co 记录或人证支撑。
2. co 不会无故失效；"查不到"只在合理边界内出现（不记指使、不记聊天）。
3. 被除名者不能再进镇（除非特赦），本季不出现特赦。
4. 镇史库封口的开启需程序；老穆的撬是违规，本季以此立冲突。
5. 本片无死亡、无重伤；"最坏"是失联与除名。

## 只保留会推动主线的设定

以上规则全部直接服务于：借名之谜（边界1/2）、老穆如何躲过 co（边界1/2/3 + 代管）、服管"信数据不信人"的冲突（边界3）、限期与停权（组织权限）、决战合法性（硬规则1/4）。
