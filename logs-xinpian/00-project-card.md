# 《服管足行志（Logs）》· 第 0 步 项目任务卡

## 项目信息

| 项 | 内容 |
|---|---|
| 片名 | 《服管足行志（Logs）》 |
| 形式 | Minecraft 服务器世界观 · 动画连续剧 |
| 集数 | 8 集 × 15 分钟，全季约 120 分钟 |
| 类型 | 生活系日常悬疑 + 情感成长（无血、无凶案） |
| 世界 | 凌霄——一个以平静著称的生存服务器，**方块小镇（城镇格局）**：街道、民居、商铺、广场、市政厅、钟楼、工坊（红石）、路灯。非农牧村落，不出现农田牧场元素 |
| 基调 | 生活类，日常温馨 + 悬疑，异常非血案命案 |

## 主要人物

- **服管**：服务器管理员 / 记录者。理性、缺失感情、容易被数据迷住、做事小心审慎。
  - 能力：**co 查询**（CoreProtect 方块操作记录，查"谁在何时何地放置/破坏/交互"）。能力克制，不赋予过多。
- **陈曦**：玩家。鲁莽的女孩、感情细腻、会玩、与镇子的自然相生（镇旁树林、河边、宠物狼阿黄、喜欢跑动探索）。直觉敏锐。
- **郭平**：新成员，男。鲁莽、笑点担当、时刻提防。擅长拆红石机关/陷阱。

## 开篇（第一集）

1. 凌霄向来平静，但三天内小镇出现此起彼伏的异常事件（巷子半夜声响、商铺招牌被调包、住户门窗被堵、红石路灯夜夜自亮、广场公告被改等），大量玩家举报。
2. 服管被推去侦查（会议上众人把差事推给他）。
3. 服管家中接到大量**举报信**（非灵异信——他们一开始并不认为有鬼），他一边读一边与陈曦梳理；陈曦听着打瞌睡，被叫醒后听计划：先赴各异常地点实地调查。
4. 郭平推门而入，得知一切，入伙。
5. 三人前往某个上报的小地点，展开第一次"对扯"（对峙/交锋）。

## 情感弧光（主线）

- 服管"摆脱没有情感"的成长：通过**（非陈曦有意，是服管导致的）暂时丢失陈曦**，换取服管醒悟自己轻视了陈曦的作用。
- 随后服管必须自己在下一次选择中做出改变（**与陈曦无关**，是他自身的转变）。
- 直到多次之后，陈曦才自己跑回来。
- 禁止军令状等夸大其词的桥段。

## 核心谜团（暗线方向）

- 异常事件的 co 记录每次都指向不同的普通玩家，但所有人都喊冤。
- 真相：有人能"借他人之名 / 绕过记录"作祟，把凌霄搅乱，以掩盖一件藏了数日的秘密。
- 幕后身份前期不暴露，但相关人物**从第 1 集就登场、言行埋伏笔**，直到后段揭晓。

## 硬约束（第一行动指南，全部适用）

- 暗线贯穿全篇，每集结尾留抓眼点/钩子。
- 反派（幕后）身份与故事前期不暴露；相关人物早早登场、言行埋伏笔。
- 不洗白收场。
- 前期抓捕/交锋不顺利、节奏不冒进、剧情不雷同。
- 陈曦活泼细腻、郭平鲁莽不拽；**三人各有贡献**。
- 限期必须执行（到点就停权，不拖戏）。
- 各单元故事服务主线，真相循序渐进（或看似循序渐进）浮出。
- **实地调查取证**，不反复安排"查资料"桥段。
- 场景充分延展、情节起伏；切场景必有动机，不高频横跳。
- 交锋有来有回、能制伏、不趋同、不"上帝视角"。
- 服管理性而平易近人，具备丰富情感层次。
- 第 7 集三线并行 + 蒙太奇式打斗（服管引开众人/骗郭平独行），结尾对决不省略。
- co 不频繁失效；只在**重点节点**点出"记录查无/被抹"，点出的一定是关键。
