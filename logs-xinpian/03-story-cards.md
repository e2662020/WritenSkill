# 《服管足行志（Logs）》· 第 3 步 节拍卡片（三幕 · 32 张）

> 整季三幕式：第一幕（A1-A10）失衡与入局｜第二幕（B1-B12）行动、鸿沟与递进｜第三幕（C1-C10）选择、高潮与新平衡。
> 每张卡标注：价值转折（开场→结尾）、前因（由谁触发）、后果（引出谁）。因果链无断点。

---

# 第一幕 · 失衡与入局（A1-A10）

**A1｜激励事件：三天异常清单**
- 内容：凌霄三天内异常频发（路灯夜亮、招牌调包、门窗被活塞堵、公告被改），镇公所会议上众人把差事推给服管——他是记录员，有 co。
- 价值转折：平静 → 不安
- 后果：服管被迫接案，进入主线。

**A2｜举报信与搭档**
- 内容：服管家收到大量举报信；他正与陈曦梳理（陈曦听睡着被叫醒），讲计划：先实地查各异常点。郭平推门入伙。
- 价值转折：孤立 → 有同伴
- 后果：三人组成调查小队，决定逐地排查。

**A3｜第一处现场：路灯案**
- 内容：查"夜半自亮路灯"：无人的红石机关，co 指向玩家小六，小六喊冤（那晚在别人家打牌）。第一次"对扯"：服管盯记录，陈曦安抚人。
- 价值转折：明确 → 存疑（co 并非绝对）
- 后果：服管意识到"co 指向与喊冤矛盾"，埋下"借名"疑点。因 A1 接案、A2 组队而得以成行。

**A4｜钩子：钟楼闷响**
- 内容：夜归路上，钟楼方向传来一声闷响。陈曦的狼阿黄竖耳。
- 价值转折：安定 → 暗涌
- 后果：钟楼进入视野（整季暗线的第一次落点）。由 A3 的走访路线自然带出。

**A5｜招牌调包案：机关自动作案**
- 内容：招牌调包案，co 又指向有人证的阿贵。郭平拆机关，发现是同一套红石触发手法——**机关自动作案，非人手动**。服管改变策略：追"机关手法"而非人名。
- 价值转折：查人 → 查机关（策略转折）
- 后果：锁定"会造这种机关的人"。因 A3 的存疑 + A4 的暗涌累积。

**A6｜撞见帮手：第一次交手**
- 内容：三人夜巡蹲守，撞见帮手搬运招牌，短促交手，帮手被打跑，留下半截机关。
- 价值转折：无证 → 有实物线索
- 后果：确认"背后有人操作、且不止一人"。因 A5 蹲守诱出。

**A7｜老穆登场："旧式钟楼机关"**
- 内容：陈曦提议问全镇唯一会修这种机关的人——红石工坊老穆。老穆热心指路，随口说"这手法像旧式钟楼机关"，把目光引向钟楼。
- 价值转折：转向钟楼（老穆看似帮忙，实为引导——伏笔）
- 后果：调查目标锁定钟楼。因 A5-A6 确定"机关手法"可追。

**A8｜钟楼地基：旧号之谜**
- 内容：三人查钟楼，地基有近期改动，co 显示操作者是**已注销三年的老玩家账号**。服管追"谁有这账号"。
- 价值转折：有主 → 无主（借名之谜）
- 后果：引入"借名/旧号"线索。因 A7 指向钟楼。

**A9｜伏击与露身手**
- 内容：钟楼遭遇帮手伏击，跑酷追逐；老穆闻声"赶来帮忙"，顺手让开一块落砖——利落身手的伏笔。陈曦发现狼阿黄对钟楼底狂叫，说"底下不对劲"，服管无视，只追数据。
- 价值转折：信任↑（老穆）／陈曦直觉被轻视（双线并进）
- 后果：老穆身手疑点埋下；陈曦直觉被无视（为 B5/B8 埋因）。

**A10｜第一幕转折：机关主控指向钟楼地基**
- 内容：追查机关主控线，全部指向钟楼地基。服管主动承担整季目标：查清钟楼之下。退出即镇子继续乱、限期逼近。
- 价值转折：被动接案 → 主动承担
- 后果：进入第二幕（下探钟楼）。由 A8 旧号 + A9 主控线汇合而成。

# 第二幕 · 行动、鸿沟与递进（B1-B12）

**B1｜下探：发现镇史库外围**
- 内容：三人从钟楼地基缝隙下探，发现一层"不该存在"的旧封口（镇史库外围），有近期被撬痕迹，co 显示是"旧号"操作。
- 价值转折：钟楼 → 镇史库（谜底外圈）
- 后果：确认钟楼下藏着东西。直接承接 A10 的主动下探。

**B2｜废宅引路（老穆"帮忙"）**
- 内容：老穆顺嘴把怀疑引向镇南废宅。三人前往，遭遇**机关阵+帮手围堵**——第一次完整打戏，团队配合制伏一名帮手。
- 价值转折：占优（抓到帮手）
- 后果：帮手成为可审讯的线索源。因 B1 之后调查路线被老穆引导。

**B3｜审讯：半真半假**
- 内容：帮手只认"收钱办事"，指认雇主是"工坊老板"。服管记录但证据软——co 只记录操作者，不记录"指使"。
- 价值转折：有线索 → 软证据（co 的边界第一次点出）
- 后果：老穆进入怀疑名单（观众+服管潜意识），但无实锤。**co 边界在此立规矩，后文不滥用失效。**

**B4｜中点：镇史库的真相初现**
- 内容：服管深挖旧号，发现旧号是当年"封存镇史库"的参与者（初代玩家）。镇史库=钟楼地下初代封存处。服管意识到异常不是"闹鬼"，是**有人要抢先取走镇史库里的东西**，异常是掩盖。风险性质改变。
- 价值转折：查异常 → 查"抢东西的人"（目标理解改变）
- 后果：主线从"生活悬疑"升级为"争物"。由 B1 镇史库 + B3 帮手指认汇合。

**B5｜陈曦的直觉 vs 服管的数据**
- 内容：陈曦靠阿黄和自然感知，反复说钟楼底"不对劲"；服管只信 co，认为她"添乱"，多次制止。两人张力上升。
- 价值转折：伙伴信任↓（服管轻视）
- 后果：陈曦疏离感累积（为 B8/B9 埋伏笔）。

**B6｜借名手法的破绽**
- 内容：服管追"旧式钟楼机关"手法，发现镇上近年所有"维修"里，老穆修过的灯/门/机关都在异常点附近；co 显示操作者是他"代管"过的旧号或他人离线时段。
- 价值转折：软证据 → 强疑点（仍非实锤）
- 后果：服管心理名单指向老穆，但证据链被"修"掉。由 B3 co 边界 + B4 旧号汇合。

**B7｜限期与停权**
- 内容：镇公所给服管限期（三日）平息异常，否则停权——异常造成镇民恐慌与生意损失。
- 价值转折：自由 → 受控（时间压力）
- 后果：服管急于下结论，压力把他推向"只信数据"。由 A 幕累积的镇民压力兑现。

**B8｜夜探钟楼（服管的错误决策）**
- 内容：服管查到旧号登录指向镇史库方向，决定夜探钟楼，**不带陈曦**（嫌她添乱），独自行动。
- 价值转折：团队 → 孤行（信任破裂外化）
- 后果：陈曦被抛下，赌气自己先跑去钟楼底。因 B5 轻视 + B7 限期双重压力。

**B9｜转折：陈曦丢失**
- 内容：服管在钟楼被帮手与机关困住；陈曦冲进钟楼底，被帮手追赶、踩中旧机关，掉进镇史库深处，被机关封住失联。服管挣脱赶到，co 显示"陈曦在此操作过"——人却不见了。
- 价值转折：陈曦在场 → 陈曦失联（重大损失）
- 后果：服管崩溃，数据第一次查不到人。因 B8 孤行 + B5 轻视直接造成。

**B10｜醒悟：第一次信人**
- 内容：服管疯找陈曦，理性崩角。他开始靠"陈曦可能留下的标记/直觉"找线索（而非纯 co），狼阿黄带路。第一次承认"我该听她的"。
- 价值转折：只信数据 → 开始信人（服管内在转变启动）
- 后果：服管找回陈曦的行动线。由 B9 的损失催生。

**B11｜反查：老穆的"帮忙"全是引导**
- 内容：回头重查，发现老穆每次"帮忙"都恰好引开调查方向；服管正面撞上老穆，证据链被"修"掉，拿不到实锤。
- 价值转折：怀疑 → 确认（老穆浮现为对手，但未公开）
- 后果：服管知道对手是老穆，需在镇史库拿实锤。由 B3/B6 疑点 + B10 醒悟汇合。

**B12｜第二幕转折：设局三线**
- 内容：服管设计：假装镇北有线索，把郭平支去镇北拆"假机关"（骗过郭平也骗过老穆耳目），自己独行下钟楼。三线分头。
- 价值转折：团进 → 三线并行
- 后果：进入第三幕决战。由 B11 确认对手 + B10 主动改变催生。

# 第三幕 · 选择、高潮与新平衡（C1-C10）

**C1｜服管线：循标记下潜**
- 内容：服管独行下到钟楼底镇史库外围，发现陈曦留的标记（身上物件做的记号），知道她还活着，循标记深入。
- 价值转折：无望 → 有希望
- 后果：服管找到陈曦行动线。承接 B12 独行 + B10 学会信标记。

**C2｜陈曦线：镇史库内的发现**
- 内容：陈曦在镇史库内醒来，发现封存的资源库与"初代旧账"（初代离开时托付的记录），明白老穆要取的东西是什么；边自救边留标记，躲开闻声赶来的帮手。
- 价值转折：被困 → 掌握关键信息
- 后果：陈曦成为"知道真相"的人，为决战提供关键证据。因 B9 掉入镇史库。

**C3｜郭平线：识破调虎离山**
- 内容：郭平在镇北拆"假机关"，发现是调虎离山，掉头赶回，沿途拆掉老穆布置的拦截机关、与帮手短兵相接（蒙太奇打斗）。
- 价值转折：被骗 → 识破
- 后果：郭平驰援钟楼（三线汇聚准备）。因 B12 被支走。

**C4｜三线汇聚：老穆现身**
- 内容：三线在钟楼底/镇史库门口汇聚。老穆卸下伪装现身，承认要取走镇史库里的东西，阻止三人。
- 价值转折：潜伏 → 摊牌（反派身份公开）
- 后果：进入正面对峙。由 A7 起埋的老穆伏笔 + B11 确认在此兑现。

**C5｜真相对话：初代旧账**
- 内容：老穆与服管对峙，揭示动机：他是初代玩家旧识，镇史库封着初代留下的资源库与"旧账"；三天前得知"有人也在找镇史库"，想抢先取走转移，不信任镇公所会公正处置。他制造异常是掩盖动静、借名是搅乱视线、帮手是封口。
- 价值转折：无知 → 真相（反派动机揭示）
- 后果：服管面临"如何处置老穆与旧账"的选择。由 C2 陈曦发现旧账佐证。

**C6｜危机选择：真两难**
- 内容：服管面对真两难：①按规矩等镇公所来人处置（旧账可能走漏、被另一拨人抢先）②当场阻止老穆并保住旧账（无外援下硬拼，风险高）。他选择后者——信自己、信团队，不再只等"记录"。
- 价值转折：两难 → 决断（证明服管价值排序：人的安全与真相 > 程序）
- 后果：进入决战。此选择是整季情感弧光的顶点，与 A3/B5 的"只信数据"形成对照。

**C7｜高潮：镇史库决战（不洗白）**
- 内容：老穆亲自下场：机关+跑酷身手+钟楼地形三合一。服管"文职"正面不敌，靠记录推理找破绽 + 郭平拆主控 + 陈曦库内策应，三人配合拿下老穆。打戏完整，老穆败。
- 价值转折：老穆占优 → 败（对抗力量最终回应）
- 后果：老穆被制伏。由 C6 选择 + C3 驰援 + C2 策应汇合。

**C8｜真相落地：旧账公开**
- 内容：服管用"co 记录 + 陈曦在库内找到的旧账"让真相落地：异常是老穆掩盖，借名是他操纵，陈曦丢失是其机关所致。老穆被除名离开（不洗白，付出代价）。镇史库的旧账按镇规处理。
- 价值转折：隐藏 → 公开（全局价值转折）
- 后果：凌霄恢复秩序。由 C7 制伏 + C5 真相 + C2 证据汇合。

**C9｜陈曦归来与服管的改变**
- 内容：陈曦脱困回来。服管第一次当面承认"我该听你的"，也承认轻视了她的作用。他此后办案方式改变——开始信人。
- 价值转折：关系破裂 → 修复
- 后果：人物弧光完成。由 B9 丢失 + B10 醒悟 + C6 选择全程铺垫。

**C10｜新平衡与钩子**
- 内容：凌霄恢复平静；镇史库门口又出现一封新的信（或新异常征兆）——下一季的线。
- 价值转折：平静（但暗涌未消）
- 后果：季终钩子。由 C8 处理旧账的余波 + "也有人找镇史库"（C5 埋）兑现。

## 因果链总览（逻辑自检）

- **A 幕因果**：异常（A1）→ 接案组队（A2）→ 首案存疑（A3）→ 钟楼闷响（A4）→ 机关作案（A5）→ 帮手现身（A6）→ 老穆引向钟楼（A7）→ 旧号之谜（A8）→ 伏击+露身手+陈曦直觉被无视（A9）→ 主控指向钟楼，主动承担（A10）。
- **B 幕因果**：下探镇史库（B1）→ 老穆引向废宅、制伏帮手（B2）→ co 边界、软证据（B3）→ 中点：争物真相（B4）→ 信任裂（B5）→ 借名破绽（B6）→ 限期停权（B7）→ 服管孤行夜探（B8）→ **陈曦丢失**（B9）→ 醒悟信人（B10）→ 反查老穆（B11）→ 设局三线（B12）。
- **C 幕因果**：循标记（C1）→ 陈曦发现旧账（C2）→ 郭平识破驰援（C3）→ 老穆摊牌（C4）→ 真相对话（C5）→ 真两难选择（C6）→ 决战（C7）→ 真相落地（C8）→ 关系修复（C9）→ 新平衡+钩子（C10）。

## 逻辑一致性检查

- **co 边界**：只在 B3（不记"指使"）点出一次能力边界，后文不滥用"co 失效"；老穆靠借名+修证据链躲过 co，不靠魔法失效。
- **陈曦丢失**：由 B5 轻视 + B8 孤行 + 限期（B7）层层造成，**非陈曦有意，是服管所致**，满足设定。
- **老穆武力**：A9 露身手伏笔 → C7 亲自下场兑现；帮手负责 B2/B8/C3 的打戏主力，无血（Minecraft 式击退/困住）。
- **不洗白**：C7 老穆败、C8 被除名付出代价，无"被冤翻案"式洗白。
- **三线**：B12 设局 → C1/C2/C3 并行 → C4 汇聚，蒙太奇打斗在 C3/C7。
- **服管成长**：A3 只信数据 → B10 开始信人 → C6 选择信团队 → C9 关系修复，弧光闭环。
- **信息表**：帮手只认"工坊老板"（不知全情）；老穆动机 C5 才完整揭示；"也有人找镇史库"为下一季保留。
