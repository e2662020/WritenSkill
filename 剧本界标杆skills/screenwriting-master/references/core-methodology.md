## 1. 用户与Agent的输入边界

用户必须提供的最低输入只有：

- 一个故事想法或已有材料。
- 作品形式；不明确时由Agent用一句话询问。

用户可以提供时长、集数、题材、参考作品、指定人物、已有世界观以及必须保留或禁止的内容。未提供时，Agent根据故事和格式提出方案。

Agent不得要求用户填写控制思想、价值转折、人物维度、压力测试、场景策略或对白行动等专业字段。Agent先推导，再以易懂的成品交给用户确认。

## 2. 主角行动梗概

整体梗概必须以主角为语法和因果中心：

```text
[主角]原本处于[初始状态]，因[激励事件]开始[目标行动]；
当[主要对抗]升级，[主角]通过[关键行动链]接近目标，
最终在[两难]之间作出选择，并以[高潮行动]造成[结局]。
```

检查：

- 每句是否以主角处境、行动、决定或后果为中心。
- 配角、组织和世界设定是否只作为阻力、帮助、线索或代价出现。
- 是否呈现“因为，所以，但是，因此”的因果，而非“然后又发生”。
- 主角是否亲自完成核心发现和高潮行动。

## 3. 世界观和规则

世界规则确认表：

```text
时代与地点：
现实基准：写实 / 近未来 / 科幻 / 奇幻 / 混合
社会运行规则：
核心特殊规则：
能力边界与代价：
组织权限边界：
信息规则：谁知道什么、何时公开
生死与现实后果：
不可临时突破的硬规则：
```

每条规则至少完成一项功能：限制主角、制造阻力、提供有代价的手段、提高风险、隐藏或释放信息、支撑伏笔回收。只有装饰作用的设定暂不进入正式规则。

禁止：

- 为解决当前难题临时增加新能力或机构权限。
- 让私人组织无理由行使警察、军队、法院或政府权力。
- 让技术、魔法或超能力只有能力没有边界和代价。
- 前后改变受伤、死亡、移动、通信或执法规则。

## 4. 世界地图或势力地图

### 自动选择

- 地理移动、探索、战争、逃亡主导：世界或空间地图。
- 商战、犯罪、谍战、家族、组织争夺主导：势力地图。
- 两者共同决定剧情：两种地图都做。

### 空间地图字段

- 核心地点和相对位置。
- 主角起点、主要路线和高潮地点。
- 危险区、限制区、安全区和关键资源。
- 移动时间、进入条件和封锁条件。

### 势力地图字段

- 主角阵营、外部敌人、内部反对者、中立或摇摆方。
- 合作、敌对、控制、收买、欺骗、血缘、委托关系。
- 权力、资金、信息和资源的关键流向。
- 每个组织的公开目标、真实目标和权限边界。

默认输出Mermaid。每条连线必须有剧情依据，不为了图面丰富添加无用关系。

## 5. 主线准入

主线是“主角因激励事件追求一个外在目标，并在递进对抗中作出最终选择”的因果链。

重要内容至少改变一项：

- 信息：主角知道或误信了什么。
- 资源：主角得到或失去什么工具、权力、证据或空间。
- 关系：合作、信任、敌对、控制发生什么实际变化。
- 风险：损失、时限、暴露程度或代价是否提高。
- 策略：主角是否必须换一种办法。
- 选择：主角是否作出影响后续和结局的决定。
- 结果：主线局势是否发生不可逆转折。

支线只有在限定篇幅内返回并改变主线时才能保留。配角私生活、世界日常、独立任务和气氛段落不能脱离主线单独扩张。

## 6. 可拍摄写作

只写摄影机和麦克风能够捕捉的内容：动作、表情、声音、物件、空间、光线、行为反应和台词。

错误：

```text
Anna意识到Vetory没有说实话，心里更加怀疑。
```

正确：

```text
Anna看一眼Vetory递来的门卡，没有接。
她把门卡编号输入自己的终端。
```

动作描写使用现在时、具体动词和短段落。不要替导演逐镜头调度，除非镜头本身是故事信息。

## 7. 时长与节奏

一般估算：一页标准剧本约一分钟；中文对白和动作约200-250字可对应一分钟，但动作、停顿和空间移动必须单独估算。

每场标注：

```text
预估时长：
外部强度：松 / 中 / 紧
情感强度：轻 / 中 / 重
```

三幕比例是功能参考，不是机械页码：第一幕约20%-25%，第二幕约50%-60%，第三幕约20%-25%。极短内容可压缩，但不能缺少进入主线、递进对抗、选择与后果。

## 8. 连续性和检查点

长片每个序列结束、剧集每集结束时记录：

```text
主角当前目标与策略：
人物位置、伤势、资源和权限：
各人物已知与未知信息：
本次关键选择及后果：
活跃线索和待回收设置：
世界规则调用情况：
下一单元必须延续的因果：
累计时长：
```

## 9. 通用自检

### 主角与主线

- 主角是否持续采取关键行动。
- 核心发现和高潮是否由主角完成。
- 删除任一重要场景后，主线是否受到实质影响。
- 事件是否通过因果相连，而非巧合串联。

### 世界与逻辑

- 组织行动是否符合权限、资源和动机。
- 线索来源、移动时间、通信、武器和执法反应是否可信。
- 高潮是否只使用前文建立的规则和能力。

### 人物

- 目标、抱负、价值观和矛盾是否能在选择中证明。
- 人物是否根据自己知道的信息行动。
- 关键选择是否承担具体后果。
- 配角是否与主角主线发生实质关系。

### 三幕和场景

- 第一幕是否把主角推入无法轻易退出的主线。
- 第二幕是否通过鸿沟、策略变化和代价递进。
- 中点是否改变理解或方向。
- 第二幕转折是否淘汰旧方案。
- 第三幕是否包含主角的危机选择、高潮行动和新平衡。
- 每场是否发生可感知的价值转折。

### 写作

- 是否可拍摄。
- 台词是否执行行动而非讲解。
- 时长是否匹配。
- 是否存在重复信息、重复追逐或重复争吵。
