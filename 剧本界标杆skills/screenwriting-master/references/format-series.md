# 多集剧集格式指南

## 核心原则

- 整季使用三幕式，每集也使用微型三幕式。
- 整季主线由主角的目标、行动、递进对抗和最终选择连接。
- 每集必须是主线的一次因果推进，而不是与主线并排摆放的小故事。
- 人物可以保持稳定；逐集只追踪压力、关键选择和后果。
- 所有分集正文、续写、修改稿、重写稿和单场返修都必须使用本文件的固定输出格式。

## 首轮配置

用户提供多少就使用多少，其余由Agent提出方案：

```text
总集数：
单集时长：
连续程度：连续剧 / 单元主线混合 / 单元剧
题材与受众：
制作尺度：低 / 中 / 高
动作、爱情、喜剧等比例偏好：
已锁定集数或剧情：
```

## 两阶段工作流

### 阶段一：整季开发

1. 项目任务卡。
2. 整季主角行动梗概。
3. 世界观与规则确认。
4. 主要人物小传和角色群矩阵。
5. 世界/空间地图或势力地图。
6. 整季主线契约与三幕式。
7. 全部分集三幕式大纲。

必须先让用户确认整季和全部分集，再进入逐集正文。

### 阶段二：逐集开发

每集依次完成：本集主线任务、微型三幕式、场景价值转折卡、对白行动设计、正文、医生和连续性检查点。前四项是内部设计，向用户交付正文时只使用本文件规定的固定格式。

## 整季三幕式

### 第一幕：全季前20%-25%

- 建立主角、主线世界和初始平衡。
- 激励事件启动整季目标。
- 主角经历第一轮阻碍，确认敌人或核心问题的一部分。
- 第一幕转折让主角主动承担整季目标，退出会付出更大代价。

### 第二幕：全季中间50%-60%

- 主角连续采取不同策略。
- 每组集数形成一次阶段推进和价值转折。
- 中点改变目标理解、敌我关系、真相或风险性质。
- 后半幕让外部压力、人际压力和内部矛盾汇合。
- 第二幕转折淘汰旧方案，触发最终危机。

### 第三幕：全季最后20%-25%

- 主线势力公开冲突，前期设置集中回收。
- 主角面对有真实代价的最终选择。
- 主角亲自完成季度高潮行动。
- 季终展示新平衡、未偿代价和自然延伸的下一季问题。

## 单集微型三幕式

无论单集90秒还是45分钟，都保留三项功能。

### 第一幕：约20%-25%

- 冷开场直接连接上一集后果或本集主线问题。
- 建立本集具体目标和限制。
- 第一幕转折迫使主角采取本集行动。

### 第二幕：约50%-60%

- 主角行动，结果偏离预期。
- 新信息或对手反应造成策略变化。
- 冲突和代价至少递进一次。
- 第二幕转折把主角推向本集选择。

### 第三幕：约20%-25%

- 主角作出选择并执行高潮行动。
- 本集主要价值发生转折。
- 集末钩子来自高潮后果或新信息，直接造成下一集因果。

90秒单集可参考：第一幕20-25秒、第二幕40-50秒、第三幕20-25秒。冷开场包含在第一幕内，钩子包含在第三幕内。

```text

  当前后果或失衡：
  本集目标：
  第一幕转折：

第二幕（约X秒/分钟）
  主角行动与预期：
  实际反应与鸿沟：
  新信息与策略变化：
```

## 逐集正文固定输出格式

每一集正文都必须使用以下格式。把所有方括号中的说明替换为实际内容，不得把模板提示语原样留在成稿中。

```text
第X集《【本集标题】》

本集人物：【人物A、人物B、人物C】本集时长：【约X分钟／X秒】

X-1 【场景地点】，【日／夜／清晨／黄昏／不明】，【内／外】

人物：【本场出场人物】

▲【环境描写。只写摄影机能够拍到的地点、光线、声音、物件和人物状态。】

▲【人物A正在完成一个具体动作。】

【人物A】（【表情／动作／语气】）：【台词。】

▲【人物B对这句话作出可见反应。】

【人物B】（【表情／动作／语气】）：【台词。】

▲【冲突升级。人物A改变动作或说话策略。】

【人物A】（【短促动作或语气变化】）：【台词。】

▲【本场发生转折，人物获得信息、失去资源、改变关系或面临新的危险。】

X-2 【场景地点】，【日／夜／持续】，【内／外】

人物：【本场出场人物】

▲【承接上一场结果，不重新讲解已经发生的事情。】

【人物A】（【观察对方／压低声音／强忍情绪】）：【试探、逼问、拒绝或威胁的台词。】

【人物B】（【回避目光／冷笑／后退半步】）：【反击、隐瞒或讨价还价的台词。】

▲【人物A采取行动，预期获得某个结果。】

▲【实际结果与预期不同，出现意外反应。】

【人物A】（【神色变化】）：【根据新情况改变策略的台词。】

▲【风险、代价或时间压力进一步升级。】

X-3 【场景地点】，【日／夜／持续】，【内／外】

人物：【本场出场人物】

▲【主角被迫在两个方案之间作出选择。】

【人物B】（【催促／威胁／恳求】）：【迫使主角立即决定的台词。】

▲【主角看向某个已经在前文建立的物件、人物或出口。】

【主角】（【作出决定后的表情或动作】）：【简短决定性台词。】

▲【主角亲自执行本集高潮行动。】

▲【行动造成明确后果，人物处境发生变化。】

【人物A】（【震惊／愤怒／难以置信】）：【回应高潮结果的台词。】

▲【出现由本集结果引发的新危险、新人物、新线索或新任务。】

【人物B】（【看向画外／声音发颤】）：【集末钩子台词。】

【黑屏】

【字幕：需要强调的信息，可选。】

【本集完】
```

### 格式执行规则

- 集标题固定写作 `第X集《标题》`。
- 标题下一行固定列出本集人物与预估时长。
- 场次编号使用 `集号-场号`，每集从 `X-1` 开始，不跨集连续编号。
- 场标依次写地点、时间、内外景，不添加镜号或导演术语。
- 每场单独列出出场人物；未在本场出现的人物不列入。
- 所有动作、环境和可见反应行以 `▲` 开头。
- 台词固定写作 `【人物】（表情／动作／语气）：台词。`；括号内只写可表演的提示，不解释心理或潜台词。
- 相邻场景必须承接前一场的结果；连续剧新一集的首场必须承接上一集钩子或其直接后果。
- 90秒单集默认使用三场；篇幅需要时可增减场次，但仍须完整承担微型三幕功能。
- 最后一场必须包含主角选择、主角执行的高潮行动、明确后果和因果型集末钩子。
- `【黑屏】`、字幕按剧情需要使用；每集必须以 `【本集完】` 收束。
- 正文不得出现“本集主线任务”“价值状态”“鸿沟”“第一幕转折”等内部分析标签。
- 不得输出“继续按照以上格式填写”“动作描写”“台词”等占位提示；必须替换成完整可拍摄内容。

## 分集准入

独立一集至少满足两项：

1. 主角获得或失去主线信息。
2. 主角获得或失去资源、权力或盟友。
3. 主要对抗力量采取新行动。
4. 主角改变主线策略。
5. 风险、代价、暴露或时限升级。
6. 主角作出影响季终的选择。
7. 设置回收并改变主线方向。

“处理港口日常”“配角独立遭遇”“单纯恋爱互动”“重复追杀”“重复董事争论”不能独立成集，除非实质改变主线。

## 主线与支线

- A线始终是主角外在目标。
- 关系线、对手线、秘密线都必须在限定集数内改变A线。
- 一条线连续两集没有改变信息、资源、关系、风险、策略或选择，应合并或删除。
- 每集A线优先；制作时长不足时，先砍不能返回主线的内容。

## 人物追踪

每集只记录：

```text
人物当前稳定目标：
本集承受的压力：
本集关键选择：
选择证明的价值观或矛盾：
具体后果：
下集必须延续的后果：
```

## 信息和连续性

维护四张表：

1. 人物位置、伤势、资源与权限。
2. 各人物已知和未知信息。
3. 设置、埋入集数、计划回收和实际回收。
4. 各势力目标、行动、损失和下一步能力。

新集不得依赖前集未建立的规则、线索或权限。发现冲突时，优先修改尚未锁定的新内容。

## 集间节奏

不同集可以在动作、调查、关系和情感强度上变化，但主线不能暂停。所谓呼吸集也必须完成关系重组、代价兑现、重要信息消化或下一策略形成。

## 剧集自检

- 整季能否用一段主角行动链概括。
- 整季三幕转折是否清楚且由因果产生。
- 每集是否拥有具体主线任务和微型三幕。
- 集末钩子是否来自本集后果，而非无关突发事件。
- 中段是否改变主线理解或方向。
- 后半季是否提高代价，而非重复前半季手段。
- 配角行动是否服务自己的目标并改变主线。
- 主角是否完成核心调查、决定和季终高潮。
- 人物关键选择是否造成跨集后果。
- 世界规则、地图、权限和信息是否连续。
- 单集时长总和是否合理。
