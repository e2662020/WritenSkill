## 1. 对白是语言行动

人物说话是为了满足某种欲望。每个对白节拍必须能用行动动词描述，例如：

- 试探、逼问、拖延、否认、掩饰
- 诱惑、安抚、威胁、羞辱、挑衅
- 求证、讨价、转移、结盟、切割
- 服软、反击、套话、设局、拒绝

“聊天、交流、解释、讨论”不是有效语言行动。人物没有目的时，场景通常没有戏剧动力。

## 2. 三项功能

对白承担：

1. **行动**：改变对方行为、力量关系或场景方向。
2. **人物**：通过用词、策略和选择表现人物。
3. **信息**：传递观众理解主线必需的事实。

高质量台词通常同时完成两项以上。只为交代信息存在的台词优先删除或改造成冲突中的工具。

## 3. 文本与潜台词

- 文本：人物实际说出的内容。
- 潜台词：人物没有直接说出的欲望、判断、恐惧、策略或关系态度。

潜台词来自具体原因：权力差、礼貌、危险、羞耻、欺骗、试探、交易或关系历史。不是故意说得含糊。

对白场景应形成：

```text
人物A语言行动 → 人物B反应 → 力量关系改变
→ 人物A或B更换策略 → 新反应 → 场景转折
```

反应可以是台词、沉默、动作、离开、交出物件、按下按钮或改变身体位置。


对白行动图不必每次完整展示给用户，但Agent必须在写对白前完成。

## 5. 人物声音

为重要人物建立声音指纹：

```text
词汇范围：专业 / 日常 / 粗俗 / 正式
句长：短促 / 均衡 / 绕行
句法习惯：完整句 / 省略 / 反问 / 命令
节奏：快 / 慢 / 停顿位置
意象来源：职业、地域、阶层、经历
回避方式：沉默、换话题、反击、玩笑、说半句
情绪失控时的变化：
绝不会说的话：
```

口头禅只能辅助，不能代替声音设计。人物在不同对象面前可以改变表达方式，但底层语言能力和经历要一致。

## 6. 信息处理

需要传递的信息优先变成：

- 攻击对方的证据。
- 谈判交换物。
- 威胁、诱惑或辩护的工具。
- 调查中被发现的缺口。
- 人物故意隐瞒或说错的内容。
- 让人物必须立即选择的事实。

禁止双方复述彼此已知的信息。复杂设定分批进入剧情，每次只给当前行动必需的部分。

## 7. 对白诊断

### 设计层

- 双方是否想从对方那里得到不同东西。
- 每轮话语是否引起反应和力量变化。
- 是否存在策略切换与场景转折。
- 对白能否推动主线或迫使选择。

设计层失败时返回场景卡或对白行动图，不能只润色句子。

### 内容层

- 文本与潜台词是否完全重合。
- 是否强行解释设定、动机或主题。
- 情绪是否由处境和行动支撑。
- 信息是否被人物用来行动。

### 语言层

- 不同人物遮住名字后是否仍可区分。
- 是否口语化、具体、简洁且可表演。
- 是否重复、空泛、书面化或故作金句。
- 沉默、动作和未完成句是否比说明更有效。

删除测试：删掉一句后，行动、人物或必要信息都不受影响，就删除。
