# 电影长片格式指南

## 核心约束

- 整部电影使用三幕式，序列负责幕内阶段推进。
- 主角行动贯穿全片，配角和支线必须返回并改变主线。
- 类型约定、世界规则、人物能力和高潮手段需在前文建立。
- 追踪人物的欲望、压力、选择和后果。

## 工作流

1. 项目任务卡与类型确认。
2. 150-250字主角行动梗概。
3. 完整世界观与规则确认。
4. 主要人物小传和角色群矩阵。
5. 世界/空间地图、势力地图，按题材自动选择。
6. 主线契约与全片三幕式。
7. 序列大纲与主线准入检查。
8. 场景价值转折卡。
9. 对白行动设计。
10. 按序列写作和三层剧本医生。

## 全片三幕式

### 第一幕：约20%-25%

- 开场用一个有效故事事件建立主角和类型基调。
- 激励事件打破生活平衡并唤醒外在目标。
- 主角的初始行动展示其能力和局限。
- 第一幕高潮迫使主角主动进入主线并承担风险。

### 第二幕：约50%-60%

- 前半幕：主角以原有理解行动，经历连续鸿沟和策略调整。
- 中点：目标、敌我、真相、风险或行动方向发生根本改变。
- 后半幕：对抗从至少两个层面升级，设置逐步回收，旧方法被淘汰。
- 第二幕高潮：主角失去主要退路、资源或关系，进入最终两难。

### 第三幕：约20%-25%

- 危机选择同时具有吸引力和真实代价。
- 高潮由主角使用前文建立的能力、关系、规则和设置完成。
- 结局展示新平衡、损失、责任和仍存在的后果。

## 序列设计

通常设计6-10个序列，每个序列由若干场景组成：

```text
序列编号：
所属幕：
主角阶段目标：
开场价值状态：
主要对抗：
行动与鸿沟：
序列转折：
结尾价值状态：
主线推进：信息 / 资源 / 关系 / 风险 / 策略 / 选择 / 结果
设置与回收：
预估时长：
```

序列不能只是相同追逐、调查或争论的集合。序列结尾必须改变下一阶段的行动条件。

## 类型与世界

确认类型承诺：观众期待的核心价值、角色、事件、风险与高潮形式。满足约定，但通过具体世界规则、人物策略和选择避免陈词滥调。

世界信息分批释放：

- 第一幕：主角行动必需的表层规则。
- 第二幕前半：对抗背后的运行逻辑。
- 中点后：能改变方向的深层事实。
- 第三幕：只回收已建立的信息，不新增万能规则。

## 支线准入

每条支线必须明确：

```text
涉及人物：
与主线的连接点：
它改变主角的什么：信息 / 资源 / 关系 / 风险 / 策略 / 选择
最晚返回主线的位置：
删除后的主线损失：
```

删除后主线无实质损失的支线不保留。关系戏也必须改变合作、信任、责任、弱点暴露或高潮选择。

## 连续性检查点

每个序列结束记录主角当前目标与策略、人物位置与伤势、权限与资源、已知信息、关键选择后果、活跃设置和累计时长。

## 长片自检

- 开场是否同时建立主角、类型和主线种子。
- 激励事件是否真正打破平衡。
- 第一幕转折是否由主角选择或不可回避后果完成。
- 第二幕是否有策略变化，而非单一阻碍重复。
- 中点是否改变理解或方向。
- 各序列价值转折是否逐级放大。
- 支线是否在限定位置返回主线。
- 危机是否为真两难。
- 高潮是否由主角亲自完成并服从规则。
- 结局是否展示代价，不用对白解释主题。
- 各幕和序列累计时长是否合理。
