## 1. 核心定义

### 故事事件

故事事件通过冲突，使人物生活中的一项价值发生可感知、具有意义的改变。价值示例：

- 安全 / 危险
- 信任 / 怀疑
- 自由 / 受控
- 无知 / 真相
- 合法 / 非法
- 占优 / 失势
- 团结 / 分裂
- 生 / 死

场景只有活动或说明、没有价值变化时，不是有效故事事件。

### 结构层级

```text
节拍 → 场景 → 序列 → 幕 → 完整故事
```

- 节拍：行动与反应改变人物策略或力量关系。
- 场景：至少一项价值发生转折。
- 序列：若干场景完成一个阶段目标并产生更大转折。
- 幕：高潮性事件改变主角的追求方向或方法。
- 故事：最终高潮完成全局价值变化。

### 鸿沟

角色根据自己对世界的理解采取行动并预期结果，现实反应却不同，形成“预期与结果的鸿沟”。有效推进循环为：

```text
欲望 → 行动 → 预期 → 意外反应 → 鸿沟 → 新认识 → 新策略
```

没有鸿沟，角色只会顺利执行计划；没有新策略，冲突只会重复。

## 2. 主线契约

Agent根据主角行动梗概生成：

```text
主角：
初始平衡：
激励事件：
外在目标与欲望对象：
主要对抗力量：内在 / 人际 / 外部
失败风险：
核心价值及开场状态：
第一幕转折：
中点转折：
第二幕转折：
危机选择：
高潮行动：
结局价值及状态：
控制思想草案：[价值怎样改变]，因为[主角在高潮中的选择]
反控制思想：[相反价值判断及其剧情证据]
```

控制思想只供结构检验，不让人物直接说出。应在高潮完成后反推修正，而不是先用主题口号绑架人物。

## 3. 三幕式

### 第一幕：失衡与进入主线

必须完成：

1. 用行动建立主角、初始平衡、能力边界和关键关系。
2. 激励事件实质打破平衡。
3. 主角产生或确认一个外在目标。
4. 对抗力量作出有效反应。
5. 第一幕转折使主角主动进入主线，并承担退出代价。

第一幕不是集中讲解世界观。设定只在主角行动需要时出现。

### 第二幕：行动、鸿沟与递进

必须完成：

1. 主角以旧认识和第一套策略行动。
2. 现实反应制造鸿沟。
3. 主角获得新信息并更换策略。
4. 冲突从至少两个层面递进，代价持续提高。
5. 中点改变目标理解、敌我判断、行动方向或风险性质。
6. 后半幕让旧办法逐步失效。
7. 第二幕转折彻底淘汰旧方案，把主角推向最终两难。

第二幕不能用重复追杀、争吵、失败或调查填充。每次行动必须产生不同信息、代价或策略。

### 第三幕：选择、高潮与新平衡

必须完成：

1. 主角面对两个都要付出真实代价的选择。
2. 主角自由地作出决定，决定证明其价值排序。
3. 主角依据前文建立的能力、信息、关系和规则采取高潮行动。
4. 对抗力量作出最终反应。
5. 结局展示新平衡、损失、责任和未解决后果。

巧合可以制造麻烦，不能替主角解决高潮。

## 4. 递进冲突

设计“冲突阶梯”，每一级至少提高一项：

- 失败损失。
- 行动成本。
- 时间压力。
- 身份暴露。
- 关系破裂。
- 法律或道德责任。
- 对手力量或信息优势。
- 选择的不可逆程度。

三层对抗按需组合：

- 内在：互相冲突的欲望、价值、恐惧或责任。
- 人际：亲密关系、合作、竞争、控制、欺骗和背叛。
- 外部：组织、制度、环境、资源、技术、法律和时间。

反派的每次行动也必须服务自己的稳定目标。不要让反派只在剧情需要时突然变聪明或变笨。

## 5. 场景价值转折卡

写场景前填写：

```text
场景编号与地点：
视点人物 / 场景主角：
场景欲望：
主线作用：
开场价值及状态：
对抗力量：
初始行动：
预期结果：
实际反应：
鸿沟：
新认识：
策略变化：
转折点：
结尾价值及状态：
新决定或不可逆后果：
必要信息及进入方式：
设置 / 回收：
预估时长：
```

### 场景通过条件

- 场景欲望具体，能在本场成功或失败。
- 对抗来自人物或世界规则，不是作者强行阻止。
- 实际结果与预期存在有效鸿沟。
- 人物因鸿沟调整策略或判断。
- 结尾价值状态与开场不同。
- 转折改变后续行动，而不仅是增加音量或动作规模。
- 信息在冲突中被发现、争夺、利用或隐藏。

若价值未改变：合并到相邻场景、压缩成过渡镜头，或重写对抗与转折。

## 6. 危机、高潮与结局

### 危机选择

危机不是“情况很危险”，而是主角必须在两个有真实价值和代价的方案中选择。伪两难的特征是一边明显正确、另一边毫无吸引力。

### 高潮行动

高潮应同时完成：

- 回答主线主要戏剧问题。
- 完成全局价值转折。
- 证明主角的价值排序。
- 使用前文设置并付出代价。
- 让主要对抗力量得到最终回应。

动作类型的高潮也必须是选择的外化，不能只是规模更大的打斗。

### 结局

结局展示高潮的结果，不重复解释主题。至少交代主角、主要关系、主线空间或组织的新状态，以及需要延续的真实后果。

## 7. 故事诊断

按顺序检查：

1. 激励事件是否打破主角平衡。
2. 主角目标是否清楚且持续驱动行动。
3. 每个主要转折是否由前序行动引发。
4. 第二幕是否通过鸿沟和新策略推进。
5. 冲突是否提高代价，而非重复形式。
6. 中点是否改变理解或方向。
7. 第二幕转折是否淘汰旧方案。
8. 危机是否是真两难。
9. 高潮是否由主角完成且遵守世界规则。
10. 结局是否展示新平衡与代价。
11. 每个场景是否发生价值转折。
12. 删除支线后是否影响主线；不影响则删除。
