# 概念引擎 —— 一句话故事、高概念与主控思想

优先级标注同前。核心立场：**在写第一场戏之前，先能一句话讲清"它讲的是什么"**（A 救猫咪；AAA 主控思想）。

## 1. 一句话故事 Logline（A 救猫咪）

一句话故事 = 用一两句话让陌生人想听下去的故事简介。四要素，缺一即弱：

1. **反讽（钩子）**：情境本身让人意外（《虎胆龙威》：来探望妻子的警察，撞上大楼被恐怖分子占领）。没有反讽→先怀疑故事本身。
2. **脑补画面**：听完能在脑中看到整部电影（含时间范围）。"一个谨小慎微的教师为了娶到深爱的女孩，必须先跟保护欲过剩的警察大舅子来一趟地狱之旅"——画面与冲突都出现了。
3. **目标观众与成本**：能看出拍给谁、大概什么体量（合家欢/低成本街区喜剧/高概念特效）。
4. **绝杀片名**：片名说清"讲的是什么"且不直白（《律政俏佳人》好过《芭比上哈佛》）。

写作公式（可组合）：

```
[一个（特点鲜明的）主角] + [意外情境/反讽] + [目标] + [最强阻力] + [风险/时限]
```

示例：一个迷路的邮差在暴雪夜把一封四十年前的信送回它本该到达的地方。

## 2. 高概念与市场验证（A）

- 高概念 = 一句话+一张海报就能说清、且让人想看的电影。它没有过时，它是"站在观众角度思考"。
- 写作前做**口头市场调查**：向陌生人推销你的 Logline，看他们眼睛是否发亮；留不住注意力，就回去改 Logline（而不是改剧本）。
- 创意枯竭时的六个激活游戏（救猫咪）：
  1. 搞笑版：把剧情片改成喜剧片（灵异车→车开始提供恋爱咨询）。
  2. 严肃版：把喜剧片改成剧情片。
  3. 水土不服的 FBI：把探员放进意想不到的环境（普罗旺斯烹饪学校卧底）。
  4. ____学校：设计不寻常的学校/训练营。
  5. 大战！！！：设计针锋相对的人物组合。
  6. 我的____是连环杀手：给日常事物加悬疑。

## 3. 主题与主控思想（AAA 麦基）

- **主题** ≠ 题材（爱情/复仇是题材）；主题 = 故事对生活的**主张**。
- **主控思想**：用一个句子概括故事的核心意义，形如"**价值 + 原因**"。
  - 例：《肖申克的救赎》主控思想≈"希望（价值）源于人在绝境中坚持做人的尊严（原因）"。
  - 例：《教父》"家族高于一切，为此付出一切的人终将失去一切"。
- 主控思想必须在**高潮**中得到最终表达，而不是靠台词说出来。
- 第1步即定主控思想；第9步（剧本医生）回查高潮是否表达它。

## 4. 概念开发输出格式（第1-2步输出）

```
# [剧本标题] 概念卡
- 片名：[绝杀片名]
- 一句话故事：[四要素齐备]
- 类型：[主类型 + 次类型]
- 主控思想：[价值 + 原因]
- 目标观众 / 体量：[谁在看 / 长片·短片·剧集]
- 反类型野心：[套路内如何出新（见 genre-matrix）]
- 灵感来源 / 硬约束：[用户提供与不可改项]
```

## 5. 概念诊断清单（剧本医生第1维用）

- [ ] 一句话故事能通过"陌生人测试"吗？（反讽+画面+观众+片名）
- [ ] 主控思想是"价值+原因"的完整句子吗？
- [ ] 主控思想值得拍吗？（过俗/过空/过争议需调整）
- [ ] 类型定位清楚吗？（类型模糊=观众预期落空）
- [ ] 这个故事非拍不可的理由是什么？（没有→继续想或换一个）
