# 结构引擎 —— 故事、幕、节拍与节奏

本文档是剧本引擎的结构方法论。每条原则标注优先级等级：
**【AAA】** 麦基《故事：材质、结构、风格和银幕剧作的原理》（最高，冲突时以此为准）
**【AA】** 菲尔德《电影剧本写作基础》、麦基《写作兵器库：故事创意指南》（中等）
**【A】** 斯奈德《救猫咪》、HBO《如何写出好故事》、《剧本：影视写作的艺术》（较低，实操技巧仍可用）

## 1. 故事的底层形状：求索（AAA）

所有故事同构为一个**求索**：

> 一个事件打破人物生活的平衡 → 在他内心激起恢复平衡的欲望 → 他踏上追寻欲望对象的求索之路 → 一路上与内心/个人/个人外三类对抗力量抗衡 → 危机中作两难选择 → 高潮行动完成价值摆动的最后一次大转折 → 结局建立新平衡。

写作自查（任何剧本先过这七问）：

1. 激励事件是否**打破平衡**（把价值钟摆推向正或负）？
2. 主角是否产生**自觉欲望**（他以为自己要什么）？
3. 复杂主角是否有与自觉欲望冲突的**不自觉欲望**（他真正需要什么）？
4. 是否形成了**故事脊椎**（贯穿全片的统一欲望与努力）？
5. 是否有**对抗力量**持续升级（内心/个人/个人外三类都要有）？
6. 是否有**危机**（主角必须在两难中作最终选择，不能两全）？
7. 高潮是否让价值发生**最大幅度的终极转折**？

## 2. 激励事件设计（AAA）

- **必须打破平衡**：不是"换个地方生活"，而是让主角失去或获得某种再也回不去的价值。
- **两种来源**：随机（巧合：天降横祸/天赐洪福）或有因（决定：主角决定 / 他者决定）。
- **必须发生在银幕上**：主情节激励事件不能让观众错过（它是"大钩子"，并在观众脑中投射出**必备场景**——主角最终对峙最强对抗力量的画面）。
- **定位**：主情节激励事件须在前 1/4 时段内发生（120分钟长片约前 30 分钟）；越接近开场越有力，但"尽快引入，务必等到时机成熟"——观众需要足以做出完全反应的人物与世界的知识。
- **创作提问**（改写率最高的场景）："可能发生在主角身上最坏的事是什么？它如何最终变成最好的事？"（反之亦然：《教父2》迈克尔成为教父=最好→孤家寡人=最坏）。

## 3. 五诫命（AAA）

1. **激励事件**：打破平衡的第一个重大事件。
2. **进展纠葛**：冲突升级、风险叠加，主角不断改变策略（不重复、不原地打转）。
3. **危机**：两难选择的时刻——主角必须在两个都有代价的选项间作终极决定。
4. **高潮**：主控思想的最终表达，价值摆动的最大转折。
5. **结局**：新平衡的建立。

## 4. 三幕结构（AA 菲尔德）

| 幕 | 功能 | 页数（120页） | 关键点 |
|---|---|---|---|
| 第一幕 建立 | 介绍人物、背景、冲突 | 1-30 | 情节点 I（第25-30页）：迫使主角进入第二幕的事件 |
| 第二幕 对抗 | 冲突升级、追求目标 | 30-90 | 中点（第55-60页）：风险升级/虚假胜利或失败；情节点 II（第85-90页）：迫使主角进入第三幕 |
| 第三幕 结局 | 冲突解决、回归平衡 | 90-120 | 高潮 + 结局 |

- 三幕比例约 1:2:1。
- **情节点**定义：把故事转向另一方向的事件——不是"发生了"，而是"发生了导致主角不得不行动"。
- 与五诫命的关系：情节点 I ≈ 激励事件/进入纠葛；中点 ≈ 进展纠葛的转折；情节点 II ≈ 危机逼近；第三幕 = 危机+高潮+结局。

## 5. 15节拍表（A 斯奈德，商业类型片骨架）

节拍位置（以110页计）与功能详见 `data/beats.csv`。要点：

- 开场画面（第1页）与终场画面（第110页）**必须镜像对比**——展示主角世界"之前/之后"。
- 主题呈现（第5页）：有人用一句话点出主题（常以提问形式）。
- 推动/催化剂（第12页）≈ 激励事件；争执（12-25页）是主角的"要不要去"。
- 第二幕衔接点（第25页）：主角**主动**跨进新世界。
- B故事（第30页）：情感线/副线，与 A 故事在第三幕衔接点（第85页）交织，给出顿悟。
- 中点（第55页）：虚假胜利或虚假失败。
- 一无所有（第75页）→ 灵魂黑夜（75-85页）→ 第三幕衔接点（第85页）：最低谷与顿悟。
- 结局（85-110页）：新旧世界碰撞；终场画面回归开场镜像。

> **优先级说明**：节拍表是商业类型片的可靠骨架（A），但当它与"求索/五诫命"冲突时，以 AAA 的因果逻辑为准——节拍可以挪、位置可以破，因果不能断。

## 6. 幕设计与序列（AAA）

- 幕是一系列序列的组合，序列是一系列场景的组合，场景是价值转折的单位。
- 每幕以一个**不可逆转的价值变化**收束（主角跨过一道不能再回来的门）。
- 设计幕时问：这一幕结束时，主角的处境/价值/关系发生了什么**不可逆**的变化？
- 高潮幕之前的幕，都在为"终极对抗"蓄积力量。

## 7. 世界背景四维（AAA）

任何故事世界用四维界定：

1. **时代**：故事发生的时期（当代/历史/未来）。
2. **期限**：故事的时间跨度（一天/一生/十年）。
3. **地点**：物理空间（一个国家/一座城/一间屋）。
4. **冲突层面**：冲突发生在内心、个人关系、还是个人外（社会/机构/自然）层面。

再加五组追问填满世界（写作前必答，答案进项目任务卡）：

- **职业**：人物靠什么为生？工作的一天怎么过？（麦基：大多数影片从不展示工作，但工作定义人物）
- **政治**：权力如何分配？（家庭也有政治；关系也有权力——"谁先表白谁先吃亏"）
- **仪式**：吃饭、祷告、做爱、告别都有仪式；仪式暴露价值观。
- **价值观**：人物认为什么值得付出生命？善恶/是非/合法非法的关系？
- **幕后故事**：人物过去哪些事件可以被采收来推进现在？（不是传记，是"可反复采收的花园"）

## 8. 体量缩放表

| 形式 | 体量 | 三幕比例 | 步骤缩放 |
|---|---|---|---|
| 概念超短片 | 1-3分钟 | 微型三幕（各30-60秒） | 只做任务卡+Logline+梗概+场景卡+正文 |
| 叙事短片 | 5-10分钟 | 三幕（1:2:1） | 省略世界观与势力图，人物 2-3 个 |
| 电影长片 | 90-150分钟 | 三幕+序列 | 完整流水线 |
| 剧集/短剧 | 整季+单集 | 整季全局三幕 + 每集微型三幕 | 先整季三幕，再逐集三幕，全部通过才动笔 |

## 9. 结构骨架产出格式（第5步输出）

```
# [剧本标题] 结构骨架
- 主控思想：[一句话]
- 故事脊椎：[主角贯穿全片的不自觉欲望或自觉目标]
- 激励事件：[事件]（位置：第X场/第X页）
- 第一幕：[序列1-2标题] → 情节点I：[事件]
- 第二幕：[序列3-6标题] → 中点：[事件] → 情节点II：[事件]
- 第三幕：[序列7-8标题] → 危机：[两难选择] → 高潮：[终极转折] → 结局：[新平衡]
```

## 10. 解说（AA/AAA 关键章：麦基《故事》第15章）

- 解说=观众需要知道的背景事实（人物经历、世界历史、规则成因）。
- 铁律：**解说要像剥洋葱一样层层揭示**，永远不要一次给足。
- 技法：把解说拆进冲突——审问、讨价、欺骗、交换中获得；或让解说本身成为行动（角色为了目的说出事实，而不是为了交代）。
- 自查：观众在每场戏开始前"已经需要知道什么"？把最低限度的信息前置，其余推迟到用得上的时刻。
- 原则：故事越往后，解说越少（高潮处几乎零解说，全在行动）。

## 11. 布局谋篇：进展纠葛的策略（AAA 麦基《故事》第12章）

- 布局谋篇=在时间轴上摆放场景，让纠葛持续升级。
- 五种策略（配合使用）：
  1. **不重复**：冲突每场都换一种类型/层面。
  2. **风险递进**：代价从小到大，直到赌上一切。
  3. **决定递进**：从容易的选择→困难的选择→两难。
  4. **对抗递进**：对手从弱到强，最后是"最强时刻的最强对抗"。
  5. **控制时间**：期限压力（倒计时）是升级最快的手段。
- 检查：把全片冲突列成清单，看是否呈阶梯上升而非原地打转。

## 12. 问题与解决（AAA 麦基《故事》第16章：常见硬伤速查）

| 硬伤 | 症状 | 解决 |
|---|---|---|
| 兴趣枯竭 | 中段观众走神 | 补鸿沟、升级风险、把解说变冲突 |
| 逻辑漏洞 | 动机不明、巧合救命 | 从人物欲望重新推导因果，删巧合 |
| 陈词滥调 | 人物/场景似曾相识 | 加矛盾（人物的内在冲突）、换细节 |
| 巧合滥用 | 关键处靠运气 | 让巧合**制造问题**而非解决问题（一次可，两次是懒惰） |
| 主控思想失真 | 高潮与主题不符 | 重写高潮或重写主控思想 |
| 情节漏洞 | 伏笔没收、规则被破 | 逐条对照"设置-分晓"清单 |

## 13. 作家的创造方法（AAA 麦基《故事》第19章）

- 从外到内 vs 从内到外：研究（背景四维+类型研究）→ 创造（人物/世界/结构）→ 反复改稿。
- 写作顺序建议：先写好**台词极少、完全动作化**的场景（开场/高潮），再补中间——用最重的两端定调。
- 作家必须"学会忍受不确定"：创作早期大量试错是常态，不是失败。
- 改稿的纪律：先整体（结构/因果），再局部（场景/对白），最后是文字润色；顺序颠倒会白改。
