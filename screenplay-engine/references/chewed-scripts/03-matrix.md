# 《黑客帝国》——嚼碎（高概念/科幻）

- 类型：高概念/科幻/动作｜136分钟
- Logline：黑客发现现实是被机器统治的虚拟牢笼，选择吞下红色药丸，成为解放人类的救世主。
- 主控思想：自由不在于知道真相，而在于选择并承担选择。

## 人物

- 尼奥：自觉=找到"什么是矩阵"的答案；不自觉=成为"那一位"。弧光：被选择→我选择。
- 墨菲斯：信念型导师，给选择不给答案；是引路人也是尼奥必须超越的期待。
- 崔妮蒂：从"预言中的爱人"到"主动相信"。
- 史密斯：特工程序，强在规则本身（无限复制）；与主角互为镜像。
- 两极分化：面对真相，尼奥呕吐接受、赛弗背叛（"无知是福"）、墨菲斯信仰坚定。

## 结构（英雄旅程变形）

| 阶段 | 位置 | 事件 |
|---|---|---|
| 平凡世界 | 开场 | 程序员/黑客，被"兔子洞"指引 |
| 召唤 | 10min | 崔妮蒂联系、墨菲斯出现 |
| 拒绝召唤 | 25min前 | 尼奥犹豫"太疯狂了" |
| 导师登场 | 30min | 红蓝药丸 |
| 跨过门槛 | 35min | 吞下红药丸，不可逆 |
| 中点 | 60min | 先知说"你不是救世主"（虚假失败） |
| 危机 | 105min | 为救墨菲斯对决史密斯（选择牺牲） |
| 高潮 | 120min | "复活"，看懂代码，击败史密斯 |
| 新平衡 | 结尾 | 预言未来，新使命 |

## 案例片段

### 片段1 开场电话追踪（原文摘录）

```
黑屏。光标像心脏一样跳动。

电话铃响。我们像正在拨号的人一样听着。

男人（画外）
嗯？

屏幕上数据飞闪："呼叫转接中……"

女人（画外）
都安排好了吗？

屏幕上："追踪程序运行中。"

（两个声音是Cypher和Trinity，
 我们像在电话三线窃听）

崔妮蒂（画外）
我说，都安排好了吗？

Cypher（画外）
你不该来替我值班。

崔妮蒂（画外）
我知道，但我就是想上这一班。

区号被锁定，前三位数字固定。

Cypher（画外）
你喜欢他，对吧？你喜欢看他？
```

### 片段2 红蓝药丸（浓缩重建）

```
INT. 废弃公寓 - 夜

墨菲斯摊开双手，掌心各有一颗药丸。

墨菲斯
蓝色药丸：故事到此为止，你醒来，
相信你想相信的一切。红色药丸：留在
兔子洞里，我带你看真相有多深。

尼奥盯着两枚药丸。窗外的雨声很响。

尼奥
（伸手）
我要看真相。

他吞下红色药丸。胃里翻涌，镜面开始
像水一样晃动。他抬手，镜子吞没了他的手。
```

### 片段3 尼奥复活（浓缩重建）

```
INT. 地铁站 - 夜

史密斯扣动扳机，尼奥中弹倒地，胸口渗出代码。

尼奥躺在地上，看着天花板上的灯管——灯管像
代码一样扭曲、重组。

他撑起身体。子弹的弹孔在胸口缓缓闭合。

史密斯后退一步。

尼奥（平静）
我选择……留下来。

他抬手，掌心挡住史密斯射来的子弹。子弹
悬停，坠落。
```

### 片段4 对白：怀疑与信仰

> 墨菲斯："你被生下来，活在一个没有知觉的牢笼……一个思想的牢笼。"
> 尼奥："如果我告诉你我不相信这些呢？"
> 墨菲斯："那正是让矩阵如此强大的原因。"
