# 《肖申克的救赎》——嚼碎（越狱/希望）

- 类型：越狱/希望｜142分钟
- Logline：被冤判终身监禁的银行家，用二十年凿开一条通向自由的隧道。
- 主控思想：希望源于人在绝境中坚持做人的尊严。

## 人物

- 安迪：自觉=洗清冤屈；不自觉=保住尊严。脊椎=尊严。
- 瑞德：安迪的镜像——早已放弃希望的体制驯化者，弧光从"希望危险"到走向安迪。
- 诺顿（典狱长）：制度性伪善，力量=体制。
- 两极分化：同一事件（安迪的音乐/图书馆/逃跑），瑞德担忧、哈德利暴怒、汤米好奇。

## 案例片段

### 片段1 开场法庭（原文摘录）

```
INT. 法庭 - 日

法官宣读判决：终身监禁，不得假释。

安迪站在被告席，面无表情。旁听席上，妻子的照片
被检察官举起，作为"犯罪动机"证据。

（画外）
安迪，你有没有罪？

安迪抬头，第一次正视法官。

安迪
（平静）
我没有杀她。我是无辜的。
```

### 片段2 屋顶啤酒（浓缩重建）

```
EXT. 监狱屋顶 - 烈日

安迪为哈德利做完了税务申报。他放下笔，指向
烈日下的狱友。

安迪
我只有一个要求：请他们喝啤酒。

哈德利盯着他，以为他在开玩笑。

哈德利
你说什么？

安迪
每人三瓶。像自由人那样，在房顶喝。

狱友们排成一排，领到啤酒。没有人说话。
安迪靠在烟囱旁，自己一口没喝，看着他们。
```

### 片段3 汤米之死与沉默（浓缩重建）

```
INT. 禁闭室 - 夜

安迪靠墙坐着，脸上没有表情。灯灭了。

外面传来狱警换岗的脚步声。他缓缓闭上眼睛，
把脸埋进膝盖。

（长时间沉默）
```

### 片段4 对白：希望与危险

> 瑞德："希望是危险的东西。希望能把人弄疯。"
> 安迪："希望是好东西，也许是世间最好的东西。好东西从不会逝去。"
