# 《惊魂记》——嚼碎（惊悚/恐怖）

- 类型：惊悚/恐怖｜109分钟
- Logline：携款潜逃的女职员在暴雨夜投宿偏僻汽车旅馆，旅馆主人的母亲似乎杀了她——而她发现的事情远比凶手更可怕。
- 主控思想：恐惧不来自怪物，而来自"我是谁"的崩塌。

## 人物

- 玛丽安（假主角）：前40分钟观众与她共谋偷钱，第40分钟被杀——视角断裂。
- 诺曼·贝茨：从害羞旅馆主人到凶手，再到"他自己就是母亲"；既是反派也是最终受害者。
- 贝茨太太（隐藏反派）：只以声音与剪影存在，从未完整露面。
- 追查线：妹妹莱拉与情人山姆，与观众的"已知"形成信息差。

## 结构（惊悚节奏）

| 阶段 | 位置 | 事件 |
|---|---|---|
| 激励事件 | 1-10min | 玛丽安偷走4万美元 |
| 逃跑纠葛 | 10-40min | 警察跟踪、换车、暴雨夜误入旅馆 |
| 假中点 | 35min | 玛丽安决定回去还钱（假承诺） |
| 视角断裂 | 40min | 玛丽安在浴室被杀 |
| 追查幕 | 40-90min | 侦探失踪、妹妹与山姆追查 |
| 危机 | 90min | 山姆拖住诺曼，莱拉潜入贝茨家 |
| 高潮 | 95min | 地下室揭示"母亲"是干尸（认知崩塌） |
| 结局 | 尾声 | 精神病医生解释；诺曼的内心独白 |

## 案例片段

### 片段1 浴室谋杀（浓缩重建）

```
INT. 旅馆浴室 - 日

浴帘被猛地拉开。一个剪影举着刀。

玛丽安尖叫。刀举起——落下。

（剪辑：刀锋、尖叫声、排水孔、
 玛丽安滑坐、血水打着旋流进排水孔）

水滴声。浴帘上，剪影转身离去。

镜头缓缓推向排水孔，最后叠化到
玛丽安睁大的眼睛。
```

### 片段2 牛奶与诺曼（浓缩重建）

```
INT. 旅馆办公室 - 夜

诺曼端来牛奶和点心，摆在玛丽安面前。

诺曼
（看着墙上的鸟标本）
每个人都活在自己的小阁楼里。母亲们……
她们是那样的宝贝。她们把儿子养大，
可儿子长大后……又娶了别的女人。

玛丽安（小心地）
你应该把母亲送进疗养院。

诺曼（声音变冷）
你是什么意思？送她进那种地方？
她是个病人……但她是我的母亲。
```

### 片段3 地下室揭示（浓缩重建）

```
INT. 贝茨家地下室 - 夜

莱拉走下台阶，手电筒光扫过一排排干尸般的
坐像。

她走到一把椅子前。一个背对的身影，穿着
母亲的长裙。

她伸出手，慢慢转动椅子——

母亲的脸：干枯的骷髅，眼窝深陷。

莱拉尖叫。身后传来开门声——诺曼举着刀，
穿着母亲的裙子和假发。
```

### 片段4 对白：字面为真的自白

> 诺曼："我们都活在自己的小阁楼里。"
> （第一次听=温情；真相揭晓后重听=恐怖。反派说的每句都是真话。）
