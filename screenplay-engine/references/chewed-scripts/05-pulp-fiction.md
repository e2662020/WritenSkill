# 《低俗小说》——嚼碎（非线性/犯罪）

- 类型：犯罪/黑色喜剧｜154分钟
- Logline：几个黑帮人物在洛杉矶的几段看似无关的遭遇，被命运咬合成一个环——顺序被打乱，因果严丝合缝。
- 主控思想：偶然是伪装的必然——每一次巧合背后都是选择与因果。

## 人物

- 文森特·维加：贯穿者，环的"针线"。他的死发生在观众已看过他之后（信息差）。
- 朱尔斯：杀手念经人，经历"神迹"后决定金盆洗手，弧光在结构中央。
- 巴奇：拳击手，"金表"段落主角，撞死了文森特。
- 蜜娅：黑帮老大的女人，"跳舞"段落，与文森特暧昧对峙。
- 两极分化：马文被爆头后，朱尔斯平静（宿命论）、文森特慌张（当下主义）、狼先生冷静（职业主义）。

## 结构（环形）

```
第1段 餐馆劫案（开场）← 环的终点
第2段 文森特与朱尔斯取回公文包 → 马文被爆头
第3段 文森特带蜜娅跳舞（独立段）
第4段 巴奇的金表（拳击/逃亡/撞死文森特）
第5段 回到文森特与朱尔斯：餐馆劫案收束（环闭合）
```

- 咬合点：公文包、马文之死、撞车、金表。因果必须严丝合缝。

## 案例片段

### 片段1 开场餐馆对话（原文摘录）

```
INT. 餐馆 - 日

两张桌子拼在一起。南瓜和兔兔坐在桌边，
喝着咖啡。

南瓜
这个国家的抢劫犯，从没想过自己的
职业道德问题。

兔兔
（四处张望）
别在这说这个。

南瓜
我说的是道理。谁都知道，抢银行比
抢酒馆更专业。可你猜怎么着？

兔兔
怎么着？

南瓜
在墨西哥，他们管抢银行的叫"制度
抢劫"，抢酒馆的才叫"抢劫"。
```

### 片段2 马文被爆头（浓缩重建）

```
INT. 轿车内 - 夜

文森特和朱尔斯坐在前排，马文坐在后座。
车行驶在洛杉矶街头。

朱尔斯（闲聊）
他妈的，布奇的老婆，屁股真翘……

枪声突然响起。

马文的头向后一仰，血喷满后座玻璃。
车内安静了两秒。

文森特（尖叫）
操！你他妈开枪打了他！

朱尔斯（同样尖叫）
枪自己走火了！我没扣扳机！

两个人手忙脚乱，血滴到朱尔斯的圣经上。
```

### 片段3 餐馆劫案收束（浓缩重建）

```
INT. 餐馆 - 日

（与片头同一场戏，但这次我们看到
 朱尔斯刚经历过"神迹"）

南瓜拔出枪，指着人群。

朱尔斯站起来，没有拔枪。

朱尔斯
我想要试一种新的方式。

他把圣经放在桌上，开始讲述子弹擦身
而过的经历。南瓜的枪口慢慢低下去。

朱尔斯
（平静）
你愿意走出去，把枪放下，还是
让我用另外一种方式跟你讲道理？
```

### 片段4 对白：仪式台词翻转

> 朱尔斯（每次杀人前）："我要试一试。正义的历程充满了妖魔鬼怪……当该隐谋害他的兄弟亚伯时，上帝问：'你的兄弟在哪里？'"
> （神迹之后，同一段经文从自我正当化翻转为真正的自省。）
