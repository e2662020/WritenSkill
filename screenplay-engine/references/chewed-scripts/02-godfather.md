# 《教父》——嚼碎（犯罪/家族）

- 类型：犯罪/家族｜175分钟
- Logline：不情愿卷入家族事业的战争英雄，在父亲遭暗杀后一步步成为教父，同时失去自己。
- 主控思想：权力以人性为代价，赢家最终一无所有。

## 人物

- 迈克尔：自觉=为家族复仇、洗白家族；不自觉=向父亲证明自己配得上继承。每次"不得不"越陷越深。
- 维托（父亲）：第一幕主角/导师，代表旧秩序。他的存在是迈克尔的压力源。
- 反派：对抗力量网络（五大家族+法律+自身道德残余），非单个人。
- 两极分化：婚礼开场，全家对"迈克尔是否入伙"反应各异（桑尼热情/弗雷多怯懦/汤姆理性/凯担忧）。

## 案例片段

### 片段1 开场（原文摘录）

```
INT. 教父的办公室 - 日（1945年夏）

黑幕上出现派拉蒙片头，白字：THE GODFATHER。

我们听到画外音："我相信美国。"

镜头对着殡仪馆老板博纳塞拉，六十岁，黑西装，
情绪濒临崩溃。

博纳塞拉
美国让我发了财。我按美国方式养育女儿，
给她自由，教她永远不要羞辱家族。她交了
个男朋友，不是意大利人。他们看电影，回家
很晚。两个月前，他开车带她出去……

（他哽咽，说不下去）
```

### 片段2 餐馆刺杀（浓缩重建）

```
INT. 意大利餐馆 - 夜

迈克尔与索洛佐、麦克卢斯基对坐。他盯着门后的
窗框——一支事先藏好的枪。

索洛佐用意大利语跟他对谈，麦克卢斯基笑着喝酒。

迈克尔起身，走向洗手间。他经过窗框，手伸进去，
枪滑进衣袋。

他回到桌边，坐下。索洛佐还在说话。

迈克尔突然拔枪，对准索洛佐的后脑。

（枪响）
```

### 片段3 洗礼与清洗交叉（浓缩重建）

```
INT. 教堂 - 日

迈克尔抱着教子，站在圣水盆前。

神父
（拉丁文）
你弃绝撒旦吗？

迈克尔
我弃绝撒旦。

—— 切 ——

INT. 酒店走廊 - 日

枪手推开房门，举起枪。

—— 切 ——

教堂。神父的声音继续。

神父
你弃绝撒旦的一切作为吗？

迈克尔
我弃绝。

—— 切 ——

另一处豪宅。枪声。

—— 切 ——

教堂。迈克尔把手指伸进圣水，在教子额前
画下十字。
```

### 片段4 对白：口头禅翻转

> 维托："一个人不能背叛他的家族。"
> 迈克尔（首次）："这不是个人恩怨，桑尼，只是生意。"
> （结尾，迈克尔的"只是生意"词义已翻转：家人已成筹码。）
