# 《疯狂动物城》——嚼碎（动画/成长）

- 类型：动画/成长/罪案｜108分钟
- Logline：小兔子警察在一座动物和谐共处的城市里追查失踪案，发现"和谐"之下隐藏的制度性偏见。
- 主控思想：偏见不来自坏人，而来自每个人都默认的规则——打破它需要先承认自己也有偏见。

## 人物

- 朱迪：自觉=成为第一个兔子警官；不自觉=被认可。弧光：证明自己→承认自己的偏见。
- 尼克：被偏见塑造的偏见者（都防狐狸，干脆当骗子）。朱迪的镜像。
- 羊副市长：制度性偏见的政治化身，被无视的弱者报复，动机令人同情。
- 两极分化：对"兔子当警察"，父母担忧、牛局长轻蔑、豹子前台热情、尼克嘲讽。

## 结构（类型片+主题双轨）

| 节拍 | 位置 | 事件 |
|---|---|---|

## 案例片段

### 片段1 开场舞台剧（浓缩重建）

```
INT. 兔子洞镇 学校礼堂 - 日

小朱迪穿着警察制服，站在舞台上。

小朱迪
（朗诵腔）
我们的世界，每个人都可以成为
任何想成为的样子！食肉动物和
食草动物，一起工作，一起生活！

（台下，小狐狸尼克正被小伙伴们
 按住，戴上防咬嘴套）

小朱迪（继续）
而今天，我要让你们看看——一只
兔子，怎么当上警察！

（后台，兔爸爸把胡萝卜递给她，
 低声说：兔子不当警察。）
```

### 片段2 朱迪发表"本性论"（浓缩重建）

```
INT. 新闻发布会 - 日

朱迪站在话筒前，记者们围住她。失踪的
食肉动物刚刚袭击了市民。

记者
兔子警官，这些食肉动物为什么突然
暴走？

朱迪（停顿了一下）
也许……这跟我们大脑里的某种东西
有关。食肉动物的天性……我们一直
在试图否认这一点。

（镜头切到人群边缘：尼克的脸色
 沉下来。他走上前，把警徽还给她）

尼克
（低声）
你知道吗，我小时候也想当个
好动物。可没人信我。现在连
你也这么说。祝你好运，兔子。
```

### 片段3 尼克与朱迪和解（浓缩重建）

```
EXT. 动物城 街道 - 日

尼克背对着朱迪，走在前面。

朱迪
（追上他）
尼克。我知道你为什么要当骗子。

尼克（没回头）
你不知道。

朱迪
你小时候想加入童子军，他们因为你
是狐狸，给你戴了嘴套。从那天起，
你就决定不再让人骗你第二次。

尼克停下脚步。他转过身，眼睛发红。

尼克
（声音很低）
你说对了。所以，我为什么还要
相信一只兔子？
```

### 片段4 对白：同一句话两种含义

> 尼克："如果全世界都觉得狐狸狡猾，你猜怎么着？你就干脆当个狡猾的狐狸。"
> 朱迪（和解时）："我以为……我也以为你是个狡猾的狐狸。"
