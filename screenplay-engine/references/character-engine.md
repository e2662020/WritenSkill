# 人物引擎 —— 欲望、弧光、两极分化与反派

优先级标注同 story-structure.md（**【AAA】** 麦基《故事》最高，**【AA】** 菲尔德/写作兵器库中等，**【A】** 较低）。

## 1. 人物的核心不是性格，是欲望（AAA）

- 人物 = 在压力下作出的选择的总和。性格标签（勇敢/善良）没有戏，**欲望**才有戏。
- 每个主要人物回答三问：
  1. **自觉欲望**：他以为自己想要什么？（说出来、可追求）
  2. **不自觉欲望**：他真正需要什么？（藏在深处、常与自觉欲望冲突）
  3. **欲望对象**：得到什么能让他的生活恢复平衡？（物质/情境/观念）
- 不自觉欲望驱动故事时，允许主角**不断改变自觉欲望**，人物就复杂了（《猎爱的人》：自认追逐完美女人，实则需要羞辱女性）。
- 若主角只有自觉欲望（如 007），脊椎=自觉目标，故事直接但扁平；复杂主人公必须有不自觉欲望。

## 2. 人物弧光 = 价值的摆动（AAA）

- 弧光不是"性格变好"，而是**核心价值的变化**：从正到负、从负到正、从一种价值到另一种价值。
- 弧光必须在**高潮的压力选择**中完成，不能靠自我宣告（"我变了"没有戏）。
- 设计弧光时问：开场价值是什么？终场价值是什么？中间哪些事件让价值一步步摆动？

## 3. 两极分化：角色网的设计原理（AAA）

- 角色设计首要原理是**两极分化**：在不同角色之间编织一张"弥漫对立或矛盾态度"的网。
- 检验标准：一组角色面对同一事件（宣布离婚/酒洒了），每个角色的反应必须**独立且显著不同**，且互成对照。
- 若两个角色对任何事反应相同 → 合并或删除其一（否则冲突机会被最小化）。
- 反应相同的唯一例外：他们是对照组的"和声"，用于突出他人差异。

## 4. 反面人物塑造原理（AAA）

- 反派（对抗力量的人格化）必须**强到足以毁灭主角**——否则高潮没有压力。
- 对抗力量可以是人、机构、自然、内心恶魔；最好的故事是**内心+个人+个人外三层对抗同时升级**。
- 反派不是"坏"，而是**价值观上与主角不可调和、且能力足以构成威胁**的力量。
- 反派塑造问三问：
  1. 他要什么？（他的自觉欲望同样成立，甚至更令人同情）
  2. 他凭什么能赢？（权力/资源/信息/魅力/信念上的优势）
  3. 主角哪一点是他无法承受的？（这决定高潮的形式）
- 反派应在第一幕内登场或显形，第二幕持续升级，第三幕在**他最强时**被主角面对（必备场景）。

## 5. 人物小传格式（第3步输出，AA 菲尔德扩展）

每个主要人物按此格式输出（配角可压缩为 3-5 行）：

```
## [姓名]（[角色定位：主角/盟友/反派/导师/对手]）
- 参考人物：[同类型经典角色，作写作参照]
- 自觉欲望：[他以为自己要什么]
- 不自觉欲望：[他真正需要什么]
- 外在目标：[可拍摄的行动目标]
- 核心缺陷：[导致他失败/困境的内在缺陷]
- 矛盾：[外在行为与内在真实的反差]
- 价值观：[愿为之付出生命的信念]
- 压力选择：[在什么处境下他必须二选一]
- 弧光：[开场价值 → 终场价值]
- 一句话概括：[人设钩子]
```

## 6. 角色原型库（快查 `data/archetypes.csv`）

英雄/导师/守卫者/变形者/影子（反派）/信使/伙伴/捣蛋鬼——按需取用，但**原型只是起点**：给原型加上具体职业、具体缺陷、具体欲望，就变成活人。禁止直接写"他是个导师型角色"，要写"他是在工地干了一辈子的放线员，坚信只要线放得直，楼房就不会塌，因此最恨投机取巧"。

## 7. 人物诊断清单（剧本医生第5维用）

- [ ] 主角有自觉与不自觉欲望吗？（至少要有自觉欲望）
- [ ] 欲望是否足够强，足以支撑整部片长？（弱欲望=平庸片）
- [ ] 每个主要人物的反应与其他人互成对照吗？（两极分化）
- [ ] 反派强到足以毁灭主角吗？
- [ ] 主角的弧光在压力选择中完成，而非自我宣告？
- [ ] 配角有没有替主角完成决定性行动？（有则删/改）
- [ ] 有没有纸片人（只有标签没有欲望）？（有则补欲望或删除）

## 8. 人物维与揭示（AAA 麦基《故事》第17章）

- **人物维**=人物内在的深层矛盾：外表/行为与真实自我的冲突（一个撒谎成性的人同时是虔诚教徒）。
- 维不是"丰富度"是"矛盾度"：每一个维=一个内在冲突，制造戏剧张力。
- **人物揭示**：真相只能在压力下揭示——观众通过选择看到人物真相，而不是通过旁白/标签。
- 写作检查：主角至少有一个维（矛盾）吗？你的高潮是否迫使他作出揭示真相的选择？

## 9. 背景故事与采收（AAA 麦基）

- 背景故事=人物过去的全部经历（传记素材），但**银幕上只采收用得上的部分**。
- 采收原则：背景故事服务于现在的选择——让人物的过去在关键选择时"回来"施加压力。
- 禁止：为交代而交代（解说章的背景叙述）；应为现在的冲突服务。

## 10. 人物与结构的关系（AAA 麦基第5章）

- 人物塑造（可观察特质）≠ 人物真相（压力下的选择）。
- **结构即人物**：情节的每一步都由人物的欲望与选择驱动；结构改变=人物改变。
- 检查：若抽掉人物欲望，情节是否还成立？成立则说明人物是情节的傀儡，需要重做。
