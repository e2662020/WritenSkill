# 场景引擎 —— 价值转折、鸿沟与场景卡

优先级标注同前。核心立场（AAA）：**场景是价值转折的单位**。没有转折的场景不是场景，是废料。

## 1. 场景 = 一个价值转折（AAA）

- 场景的定义：在**相对连续的时空**里，通过冲突，人物生活价值发生一次从正到负或从负到正的变化。
- 转折 = 价值负荷的**符号翻转**：爱→恨、生→死、自由→囚禁、希望→绝望（或反之）。
- 没有翻转（价值从正到更正，或原地不动）的场景 → 删掉或合并进其他场景。
- 单一价值在两个极端之间可被拆细（公正/不公、真诚/欺骗、生存/死亡），但每次转折必须**可感知**。

## 2. 鸿沟（AAA）

- 鸿沟 = 人物的**预期**与**现实反应**之间的裂缝。
- 主角采取行动，预期得到 A 反应，现实给了 B（且 B 更有信息量）——鸿沟打开，观众被吸入。
- 写作方法：先问"主角这一招期待什么效果"，再设计"现实给他什么反效果"。
- 每场至少一道鸿沟；鸿沟越大，情感冲击越大。

## 3. 场景内的结构（AAA）

1. **场景欲望**：主角这场戏想要什么？（具体、可拍摄）
2. **对抗**：谁/什么在阻挠？用什么方式？
3. **行动与预期**：主角出招，预期对方怎样反应。
4. **鸿沟**：实际反应与预期的落差。
5. **策略变化**：主角换一招（或放弃、或升级）。
6. **转折**：结尾的价值符号与开头相反。
7. **新决定/不可逆后果**：转折留下的钩子，把观众推入下一场。

## 4. 场景价值转折卡（第6步输出，每场一张）

```
## 场 [编号]：[场景标题]
- 场景欲望：[主角这场要什么]
- 开场价值：正/负（[具体价值]）
- 对抗：[阻力与方式]
- 行动与预期：[出招] → 预期[反应]
- 鸿沟：[现实反应]
- 策略变化：[下一招]
- 结尾价值：正/负（[具体价值]）← 必须与开场相反
- 新决定/不可逆后果：[钩子]
- 主线作用：[这场改变了主线的信息/资源/关系/风险/策略/选择/结果中的哪些]
```

## 5. 递进冲突（AAA）

- 进展纠葛的铁律：**不重复**。同一类型的冲突只允许一次（打两次架要有质的升级，不是换个地方再打）。
- 递进的三个层次：风险递增（小损失→大损失）、选择递增（易→难→两难）、对抗递增（弱→强→最强）。
- 检查：把全片冲突列出来，看是否呈阶梯状升级，还是原地打转。

## 6. 场景的连接（AA / AAA）

- 场景间用**因果链**连接：上一场的"新决定/不可逆后果"触发下一场。
- 允许策略性插入：解说场景、过渡场景、氛围场景——但每条支线/每场戏通过"主线准入检查"（见 SKILL.md）才算数。
- 时间跳跃、平行剪辑只改变呈现顺序，底层因果不能断。

## 7. 场景诊断清单（剧本医生第3维用）

- [ ] 每场有可感知的价值转折吗？（没有→删或并）
- [ ] 每场有鸿沟吗？（没有→设计反效果）
- [ ] 场景欲望具体可拍摄吗？（"想要幸福"不合格，"想借到那辆车"合格）
- [ ] 冲突是否重复？（重复→升级或删除）
- [ ] 收尾有钩子推入下一场吗？
- [ ] 场景是否只推进了"信息"而没改变"价值"？（只交代信息=解说场景，需压缩）
