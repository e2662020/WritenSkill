# 类型矩阵 —— 类型套路、价值负荷与反类型

优先级标注同前。核心立场（AAA）：**类型决定价值负荷与观众预期**；套路是地基，反套路是屋顶。

## 1. 类型 = 价值负荷的契约（AAA）

- 每种类型承诺给观众一种**价值**与**体验**：恐怖片=恐惧/生存，喜剧=荒诞/秩序恢复，爱情=联结/分离。
- 类型定义观众的预期：写类型片必须先**忠实恪守套路**，再**巧妙变更**——先给观众想要的，再给观众没想到的。
- 类型可以组合（惊悚+爱情、科幻+家庭），但组合后价值负荷要自洽。

## 3. 选型规则

- 用户给了题材（"写一个高考复读的故事"）→ 用题材定位类型（成长/伙伴）→ 查套路与反套路。
- 类型冲突（想写"悬疑"又想"合家欢"）→ 提示价值负荷矛盾，让用户选主类型。
- 剧集/短剧优先选"类型张力可持续"的类型（犯罪/职场/家庭），慎选"一次性反转"类型。

## 4. 反类型三板斧

1. **换主角类型**：把通常由强者担任的类型主角换成弱者（《虎胆龙威》：警察不是特工）。
2. **换价值重心**：类型承诺的胜利变成代价（《教父》：赢得权力，失去一切）。
3. **换结构形式**：线性变非线性（《低俗小说》），单一变多线（《疯狂的石头》式）。

## 5. 类型诊断清单（剧本医生第2维用）

- [ ] 类型明确且观众预期被兑现了吗？（前 1/4 之内让观众知道"这是哪种电影"）
- [ ] 套路是否忠实？（连套路都不给，反套路无从谈起）
- [ ] 反类型手段是否服务于主题而非炫技？
- [ ] 组合类型的价值负荷是否自洽（没有互相拆台）？
