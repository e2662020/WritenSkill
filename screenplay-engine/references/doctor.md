# 剧本医生 —— 双重检查：格式 + 内容 + 返工

剧本医生在正文交付前执行**两道检查**。格式不过关不进内容诊断；内容不过关不交付。

优先级标注同前（AAA 最高）。**冲突裁决规则：任何两原则冲突时，以 AAA（麦基《故事》）的因果与价值逻辑为准，AA 次之，A 的实操技巧（节拍位置等）可以调整。**

## 第一道：格式检查（确定性，脚本执行）

对 SPL 正文运行：

```bash
python scripts/validate-spl.py 剧本.md
```

校验项（详见 `references/spl-spec.md`）：

1. frontmatter 完整（title 必填，type 取值合法）
2. 场景标题三段式（`# INT./EXT. 地点 - 时间`，场号连续）
3. 镜头/字幕不悬空（在场景之后）
4. 角色提示-对白配对（无悬空角色）
5. 括号提示上下文合法（不解释意图）
6. 转场命令合法，`FADE OUT.` 收尾
7. 蒙太奇列表归属正确
8. 无三级标题、动作段不以括号开头

**脚本报错 = 返回第8步改格式；脚本通过 = 进入第二道。**

## 第二道：内容诊断（十维，逐维打分 0-5）

对每一维，先给证据（具体场次/台词/位置），再给结论（通过/待修），最后汇总。5 分制：≥4 通过，3 待修，≤2 返工。

### 第1维 概念与主控思想（读 `logline-and-concept.md` + `hbo-seven-elements.md`）
- Logline 四要素；主控思想是"价值+原因"完整句；高潮是否表达主控思想。
- HBO 想法五问与七要素（惩罚性/相关性/原创性/可信性/改变命运/娱乐性/意义性）逐条过闸；60/30/10 优先修想法。

### 第2维 类型契约（读 `genre-matrix.md`）
- 类型明确；前 1/4 兑现观众预期；反套路服务于主题。

### 第3维 主线与因果（读 `story-structure.md` + `story-framework.md`）
- 主线以主角行动为因果链；支线通过主线准入检查；配角不替主角完成关键动作。
- 累进检查：事件是否由前因推出（无跳跃）；每段情节概括是否含冲突可能。

### 第4维 结构完整度（读 `story-structure.md`）
- 激励事件 ≤ 前 1/4 且打破平衡；五诫命齐备；三幕/节拍关键点到位；中点与情节点位置合理。

### 第5维 场景价值转折（读 `scene-craft.md`）
- 每场有可感知转折；有鸿沟；冲突递进不重复；场尾有钩子。

### 第6维 世界规则一致（读 `story-structure.md` §7）
- 背景四维清晰；硬规则无临时突破；能力边界与代价一致。

### 第7维 人物欲望与压力选择（读 `character-engine.md`）
- 主角有自觉/不自觉欲望；角色两极分化；反派强到足以毁灭主角；弧光在压力中完成。

### 第8维 对白行动与潜台词（读 `dialogue-engine.md`）
- 每句台词在执行语言行动；无直接说心；无信息倾倒；人物声音可辨。

### 第9维 可拍摄性与时长（读 `spl-spec.md` + `screenplay-format.md` + `craft-of-script.md`）
- 无心理直述；动作可拍；体量符合形式；连续性无遗漏。
- 语言观：清晰日常、词汇精确；情感观：每场是否制造了观众能体验的情感；观众观：观众是否被放在第一位。

### 第10维 设置与伏笔回收
- 开场建立的每个设置要么回收，要么被删除；无"留而不收"的断头线（设置-分晓对照表）。

## 返工路由

| 发现的问题 | 返回步骤 | 修改对象 |
|---|---|---|
| 格式错误（脚本报错） | 第8步 | 正文 SPL |
| 对白无行动/潜台词差 | 第7步 | 对白设计 |
| 场景无转折/冲突重复 | 第6步 | 场景卡 |
| 幕或序列失焦/节拍缺位 | 第5步 | 结构骨架 |
| 人物扁平/反派太弱 | 第3步 | 人物系统 |
| 世界规则临时突破 | 第4步 | 世界观 |
| 类型承诺落空 | 第2步 | 类型定位 |
| Logline/主控思想不成立 | 第1步 | 概念卡 |

返工原则：**只改问题所在步骤及受其直接影响的已确认内容**；改完重跑第一道格式检查 + 受影响维度的诊断。
