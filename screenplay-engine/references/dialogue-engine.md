# 对白引擎 —— 语言行动、潜台词与人物声音

优先级标注同前。核心立场（AAA）：**对白不是信息传递，是行动**——每一句台词都在做一件事。

## 1. 语言行动（AAA）

- 每句台词 = 一个**语言行动**：请求、威胁、试探、拒绝、指控、安抚、引诱、转移话题……
- 写作前为每句台词标注它的行动；标不出行动的台词删掉或改写。
- 语言行动库（40+种）见 `data/dialogue-moves.csv`，写作与诊断时检索使用。
- 对白设计格式（第7步输出）：

```
角色：欲望（这场戏他要什么）/ 语言行动（这句话在做什么）/ 对方预期反应 / 实际反应 / 策略变化
```

## 2. 文本与潜台词（AAA）

- **文本**：台词的字面意思；**潜台词**：台词真正表达的东西。
- 规则：**人物不会说出自己真正的感受与意图**。当一个人物直接说出内心（"我很爱你""我怕极了"），台词即死。
- 潜台词手法：
  - **回避**：问 A 答 B（答非所问暴露真实焦虑）。
  - **转移**：把情感投射到物件/第三者（谈论天气，实则谈分离）。
  - **反向**：嘴上说放弃，行动仍在追（语言与行为的矛盾最有张力）。
  - **试探**：用问题钓对方的真实立场。
- 检验：把台词换成"他在做什么"——如果一句话不能改写为可见的语言行动，就重写。

## 3. 人物声音（AAA / A）

三个变量区分每个人物的声音：

1. **用词**：职业词汇、口头禅、文化背景词（放线员说"线"，律师说"程序"）。
2. **句长与节奏**：长者说长句、少话者用短句；紧张时句子变短。
3. **话题**：人物总把话题拉回自己最在意的事（吝啬鬼谈钱，母亲谈孩子）。

检验：把台词遮住人物名，读者能否认出说话人？认不出=声音没立起来。

## 4. 对白写作硬规则

- **禁止**信息倾倒：用台词讲解双方都知道的设定 → 拆成冲突中的交换（审问/讨价/欺骗）。
- **禁止**括号解释意图（`（他其实很害怕）`）→ 把害怕写成动作与潜台词。
- **禁止**说教与空泛独白（"这个世界需要更多正义"）→ 具体化：让人物为具体一件事争辩。
- **允许**打断、抢话、答非所问——真实对话是回合制攻防，不是问答试卷。
- 每场对白结束，至少一方改变了立场/情报/关系（否则这场的对话没推进戏）。

## 5. 对白诊断清单（剧本医生第6维用）

- [ ] 每句台词都在执行语言行动吗？
- [ ] 有直接说出内心的台词吗？（有则改潜台词）
- [ ] 有信息倾倒段吗？（有则拆进冲突）
- [ ] 遮住人名能分辨说话人吗？
- [ ] 括号里有没有"解释意图"？（有则删除）
- [ ] 对话回合有没有攻防（不是一问一答流水账）？
- [ ] 这场对话结束时，关系/情报/立场是否发生了变化？
