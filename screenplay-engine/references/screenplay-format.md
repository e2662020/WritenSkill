# 剧本格式速查 —— 行业标准与 SPL 渲染目标

本文件说明剧本的**行业标准版面**（渲染目标）。SPL 语法规范见 `references/spl-spec.md`；正文写作强制使用 SPL，本文件用于理解每个元素在成品 PDF 中的位置。

## 1. 好莱坞标准版面（render_pdf.py 已实现）

| 元素 | 位置与样式 |
|---|---|
| 页面 | A4 / Letter；上下 1"，左 1.5"，右 1" |
| 字体 | 等宽 12pt（英文 Courier；中文 Noto Sans SC Medium(500)/Bold(700) 11pt，行距 ≥1.25 倍） |
| 场景标题 | 距左 1.5"，加粗大写：`INT. 咖啡馆 - 夜` |
| 动作 | 距左 1.5"，行宽约 6" |
| 角色名 | 页面居中、大写加粗（距左约 3.7"） |
| 括号提示 | 角色名下方一行、同位置、斜体 |
| 对白 | 距左/右各 2.5" 的居中块，行宽约 3.5" |
| 转场 | 右对齐、大写（FADE IN: / CUT TO: / FADE OUT.） |
| 页码 | 页脚右对齐；页眉为「标题 · 作者」 |
| 封面 | 标题大字居中、作者、类型、时长、Logline |

## 2. 中文剧本惯例

- 中文对白用全角标点；括号提示用全角括号 `（ ）`。
- 人物名与台词之间可用冒号或分行（SPL 统一用角色提示行 + 对白段）。
- 时间限定词：日 / 夜 / 黄昏 / 黎明 / 连续（不用"白天/晚上"混写）。

## 3. 一页剧本 ≈ 一分钟银幕时间（行业经验值）

- 每页约 55 行、约 450-550 个字符。
- 120 分钟长片 ≈ 110-120 页剧本。
- 对白多的页跑得快，动作多的页跑得慢——用此估算体量是否达标（第9维用）。

## 4. 常见行业禁忌（可拍摄写作的版面体现）

- 不在动作段写摄影机指令（除非导演意图）："镜头缓缓推近"应写成 `## 推近` 镜头标题。
- 不写"我们看见/我们听到"（新版格式已淡化）；直接描述所见。
- 角色首次登场：场景标题后加 `（40岁，狱警制服）` 括号描述。
- 电话/画外音：角色名后加 `（画外）` / `（OS）` / `（V.O.）`。
